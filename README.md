## 微信体验包构建

安装 Node.js 和 pngquant 后运行 `node tools/build-wechat.cjs`，再将 `dist/wechat` 导入微信开发者工具。不要直接上传 `game`：开发目录含历史资源，会超过微信包体限制。

发布配置位于 `tools/wechat-release.config.json`，可调整输出目录、PNG 压缩质量、版本说明及包体上限。构建只复制当前玩法所需文件，在产物中压缩 PNG，并将素材作为资源分包加载；原图不变。构建报告写入 `dist/wechat-build.json`。

本次发布目录约 17.2 MiB，主包约 1.9 MiB；22 项领域测试通过，模拟器已验证首页和五名武将资源加载。手机实际运行与后台体验版设置仍需分别确认。后续优先考虑按实际出战阵容加载武将，降低启动内存；本次未改动战斗规则及存档结构。

本仓库排除账号录制战报、验收日志、本机配置、历史备份，以及包含原协议固定密钥的旧业务脚本 `game/subpackages/main/game.js`。默认本地入口不加载该脚本；历史回放模式依赖的原业务脚本和 `game/replay-data/` 不随仓库分发。说明中提到的截图对比 HTML 和 `evidence/` 仅在原开发机保留。素材重提取及原始摘要核验工具依赖原开发机外部资源路径，不能视为跨机器构建命令。

## 直接玩

1. 首页点击「整军出征」。初始拥有赵云和三名张飞，其中赵云、一名张飞已经上阵。
2. 拖动备战席武将到己方三排。拖到已有武将的格子会交换；也可以先点击武将，再点格子。
3. 选择张飞，点击「详情 / 合成」，可选择「原地合成」或「随机合成」。需要三名相同、同阶武将，最高三阶。
4. 点击「开始战斗」。近战会寻路接敌，远程会在射程内出手；支持 1×、2×、4× 和跳过动画。
5. 获胜后从三名武将中选择一名，或者只领取军资。完成结算后进入下一关；失败保留阵容，可调整后重试。
6. 「军营」可招募和刷新；「武将」可查看五名武将的模型、属性和技能；「演武」可试阵，不推进关卡、不产生奖励；「军略」有规则说明。

阵容、经济、招募列表、战果自动保存。战斗开始时先保存结果，再播放动画；中途退出后，首页会显示「查看待领取战果」。领奖只能生效一次。

默认玩家档为 `sanguo.local.campaign.v2.player`，上一个快照另存备份键。本轮自动验收使用独立的 `sanguo.local.campaign.v2` 测试档，保留测试进度，没有混入玩家新档。

## 原版核对与本地规则的边界

本轮通过你打开的「开黑自走棋」窗口查看了远征地图、布阵入口、单位详情和要塞页面，并结合原客户端代码核对了六列透视棋盘、原地/随机升级分支与选将结构。

**伤害公式、AI 寻路、五名武将的具体技能、招募经济、羁绊、敌阵生成和关卡成长采用本地可配置规则。** 没有取得原服务器的完整算法，因此不把它们标为原服务器等价复刻。

本地「军营」是招募页面；原版要塞里的矿场、装备生产、黑市广告等系统尚未复刻。本地章名用于关卡分组，目前没有复刻原远征地图的全部分支事件。

## 配置与代码

- `game/play/config.js`：经济、容量、人数、合成、成长、敌阵、时间步、存档键、主题与棋盘布局。
- `game/play/roster.js`：五名武将的属性、射程、攻击间隔、技能与职业。
- `game/play/campaign.js`：纯领域操作与事务，独立于 Cocos 和微信。
- `game/play/combat.js`：纯战斗模拟器，输入阵容，输出带时间的移动/攻击/伤害/死亡事件。
- `game/play/storage.js`：微信本地存储适配器。
- `game/play/assets.js`：多武将本地资源仓库。
- `game/play/widgets.js`、`view.js`：通用绘制控件和交互页面；动画只消费战报，不决定奖励。
- `game/play/boot.js`：独立引擎启动与外网阻断。
- `game/mode.config.js`：默认 `local`。保留 `replay` 调试入口；原录制验收仍以 `sanguo-sample` 为准。

新增函数都有职责注释。可继续演进的重点是把 `view.js` 拆成页面控制器、将当前一次性预加载改为按出战阵容加载，并为规则版本提供显式存档迁移；这些优化应保持当前领域层和存储端口不变。

## 素材与工具

五名武将均使用 `D:\Games\Warcraft3\ExtractedAssets` 中「真三国无双3_1_9dai版无CD无限蓝」的模型和配套贴图。它们是原地图使用的老式低模美术，不是新制作的高清人物。

`source-assets/<武将>/animations.json` 保存模型路径、源动作、贴图依赖及 SHA-256。赵云来源副本沿用 `source-assets/mdx`。渲染配置为 `tools/*.render.json`，赵云沿用 `render.config.json`。

适配流程为：MDX 实际渲染 → 透明序列 → Spine 附件动画。根据待机图的有效像素边界统一脚底和显示高度，避免不同模型占据不同棋格。全部 **791 帧、39 个动作** 已在原 Cocos 3.8.5 引擎解析。三国行军图和战场背景沿用上一阶段生成素材，提示词保存在 `source-assets/generated-backgrounds.json`。
