# 1.0.215 关羽跳劈动作修正

问题：旧跳劈播放skill2，源动作是Spell，只有施法姿势而没有下劈；旧刀光只在目标受伤时出现，施法者没有挥刀轨迹。

修正：复用原Attack-1图集的持刀姿势组合五个方向的专属jumpCleave时间轴；举刀腾空、向下劈刀、落地收势。第6号攻击帧作为落刀帧，在原0.36秒伤害时刻到达；收势占原命中延迟的40%。不新增或重画美术图集，不改变普攻和本体技能动作。

刀光在下落阶段从关羽身前向下扫出，即使没有存活受击对象仍能看见挥刀。临时视觉锁避免移动/普攻/待机回调覆盖下劈；连续阵亡合并正在播放的跳劈表现，每次追斩真实伤害仍逐次结算。死亡和页面结束撤销补间及视觉锁。

触发条件、55%伤害、范围及命中延迟不变。

验证：763项全量测试通过；补充统一回收后20项专属相关测试通过。原帧检查图evidence/guanyu-action-inspection.png确认Spell无劈刀动作、Attack-1包含可复用的持刀帧。当前开发者工具没有就绪的游戏实例，尚未完成真机动态视觉验收。

结构：专属时间轴生成与动作呈现独立于战斗结算；后续其他武将需要专属动作，可继续采用源帧选择配置，避免向伤害循环增加表现分支。
