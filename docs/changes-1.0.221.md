# 视频回退不含关卡系数的通关基准

- 首次可回退时，目标为A＝本章初始玩家基准×最近通关使用的累计系数；不再叠加普通、精英或Boss系数，也不包含通关后新增幅度。
- 统一计算本关实际目标曲线，再除以本关系数保存累计系数，兼容现有战斗倍率、旧锁定快照和恢复算法，无需重复乘除或重抽敌阵。
- 已经处于A或更低仍失败：第1～3章乘0.8，第4章起乘0.85。无可用历史通关记录时沿用旧兼容锚点；最低系数仍遵守原安全下限。
- 原失败恢复目标不下降；第1～3章三次、第4章起两次恢复的规则不变。普通重试不减难，重复广告领奖由现有事务保护。
- 新参数集中在 `enemy-light-balance-config.retryChapterPolicies`，由 `enemy-cycle-policy` 提供统一章节策略。
- 测试覆盖第1～8章三类关卡首次回150、连续回调、重载、普通重试、已低于锚点旧档以及恢复到原Boss目标270。

示例：初始100、原累计2、Boss加成1.35、最近通关系数1.5。原270，首次视频150；前三章后续120、96、76.8，第四章起127.5、108.375、92.11875。
