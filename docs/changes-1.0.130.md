# 1.0.130

第二至第五阶段普通、精英关主力按上阵队伍等级分布分配，采用最大余数法保留各等级人数占比，余数相同优先高阶。之后按已有路线及关卡类型配置给予升一级名额，先提升低阶单位，单名最多一级，最高五级。人数、配装覆盖率、低级援军、第一阶段及各节尾王规则保留。

例：我方4、4、2、2、2，对应六名主力的普通关开局为4、4、2、2、2、2；低级援军仍按原公式另外加入。

通过共用 expedition-stats 比较穿戴前后生命与攻击/攻击间隔的静态强度，补偿倍率为1+正向增益比例×0.25，上限1.15。基准与实际使用同一天赋、羁绊上下文，保留原永久培养倍率，避免将其再次全额补偿。此估值不等于胜率，不对控制、治疗或专属技能做虚假的精确战力折算。配置位于enemy-stage-config.power。

首次开战锁定等级与倍率，重试不重抽；新节点重新计算。策略版本7迁移旧缓存，未领奖战报保留。

543项测试通过，覆盖60章第二至第五阶段全部普通及精英节点、混阶主力、装备增益及只读性、同节点锁定、下一节点重算、旧缓存迁移；已有保护期及尾王用例持续通过。

架构：新增enemy-team-profile将分布配额和静态属性评估从生成器分离；后续可将快照中的等级、属性及配装计划汇总为单一遭遇策略对象，供生成、预览、迁移共用。
