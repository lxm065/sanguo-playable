# 1.0.127 章末尾王精锐配额

每章第五节首领：敌方最高级为实际上阵最高级加一，上限五级。未达到同五级条件时最高级1～2人；我方已有五级时，敌方五级人数为我方上阵五级人数加2～3人，受棋盘18格容量限制。其他主力低一级，低级援军规则保留。空阵仅以持有武将作预览。关卡种子决定配额，重绘不随机变化。首次开战锁定等级、人数与属性倍率。

新模块 final-boss 与配置独立于路线人数预算。首章特殊人数预算仍保留；必要时补足满级名额，但不超过棋盘容量。敌阵策略版本升至4以迁移旧缓存；待领奖战报保持原样。

实际战力继续使用 enemy-growth：章节/经济倍率、天赋倍率、装备进阶倍率相乘，再结合章节基础曲线和阵容修正。天赋倍率为1+min(35%,天赋等级×0.4%+树节点总等级×0.3%)；装备进阶倍率为1+min(25%,全装备平均进阶等级×2.5%)。原有敌方配装、装备强度和重试减压继续生效。没有额外叠加未经约定的新倍率。

精英关未调整：与同位置普通关相比人数+1，升阶比例+15个百分点，属性基础倍率×1.05，装备覆盖配置75%（普通50%），每名覆盖单位1件；路线中段以后升阶比例按max(0,(进度-0.35)/0.65)×0.5计算，普通最高50%、精英最高65%。低级援军另加，受18格上限限制。

533项测试通过，包括60章不同上阵最高等级和满级数量、备战席不计入、培养后真实生命攻击提高、缓存迁移与战报保护。建议今后把敌阵视觉预算与实际战力倍率保持独立，避免再次通过大批满级将间接抬高难度。
