# 远征交互与本地战斗改造

本轮落实合成、分类通关奖励、新人福利、装备穿戴四条交互链。**这仍是本地可玩版，尚不等同于原服完整战斗复刻。** 微信导入目录仍为仓库的 `game`，不执行微信上传。

## 已实现

- 双栏合成：预览下一阶同名武将与未知随机武将；原地、随机、视频定向三条路径。定向先选目标，三合一保留所选 UID 与位置，被消耗单位的装备返回背包。首个教学节点不开放定向。
- 普通胜利：三个兵种选一，有放回抽样允许重复；视频完成刷新为二阶候选。候选、阶级、刷新和待领取战果一起落盘。满仓时可明确放弃选将，避免卡死。
- 精英胜利：只发装备，不再发兵种三选一。当前本地掉落池有九件配置装备，图标从已有原包导出。
- 新人福利：三星关羽 → 龙心 → 10000钻石。广告取消和失败不发奖，同一次完成凭据不能重复领取；重开远征不重置已领取进度。
- 战斗底栏：不同武将计数的八项三国羁绊、装备背包与前进入口。
- 武将详情：最多三件装备，支持穿戴、转移、卸下，使用共用属性计算。技能说明分页，保留完整原始文案；当前本地只接入主技能，页面有相应提示。
- 21人运行名册沿用已确认章节条件；七位主公不加入棋子池。旧存档诸葛亮保留兼容，不加入新掉落池。新档为三个一阶许褚；不重置旧玩家阵容和金币。
- 首次正常胜利100经验，跨过90经验门槛到等级2并增加一个上阵名额。第18章之前最高4阶，之后开放5阶。
- 五个原有动画角色继续使用原资源，其余角色使用已确认的头像棋子。本轮不生成战斗模型或动作。

## 配置与职责

| 文件 | 用途 |
| --- | --- |
| `game/play/expedition-data.js` | 只读原始阶级属性、技能说明；由导出工具生成 |
| `game/play/expedition-config.js` | 本地掉落、装备效果、经验、福利、主技能策略与布局参数 |
| `game/play/expedition-roster.js` | 21人映射与旧角色兼容 |
| `game/play/expedition.js` | 事务、合成、发奖、广告凭据、装备归属和存档校验 |
| `game/play/expedition-stats.js` | 羁绊人数与有效属性只读查询 |
| `game/play/expedition-combat.js` | 独立确定性本地模拟器 |
| `game/play/expedition-view.js` | 双栏合成、分类奖励、装备与福利交互 |
| `source-assets/expedition-equipment-icons.json` | 九张包内图标的原始来源 |

原始 `hero_cfg.json`、`hero_skill_cfg.json` 只读导出，不覆盖原件。新增字段放入原存档的 `expedition`，事务嵌套只在最外层写盘；磁盘失败回滚随机种子、物品、单位与奖励状态。

## 尚未完成的原版一致性

- 原服模拟器、伤害公式、随机掉落权重未恢复；当前寻敌、攻速基线、护甲公式、主技能时序使用明确的本地配置。
- 次级/三/四技能、引导持续伤害、精确直线范围、召唤和复活尚未完整接入；主技能部分机制也有简化。原始技能说明保留供后续对照，不能把文案存在当作全部效果已实现。
- 装备只接入九件固定效果；完整41件、随机词条、强化及非叠加规则尚未复刻。战鼓暂只实现攻速，未实现冷却缩减。
- 经验前两档90/300有记录依据，后续600/1000/1500为本地成长配置。旧档迁移保留既有胜场对应等级，不反推历史经验。
- 地图继续沿用既有本地分叉路线，敌阵和后续章节没有原服等价证明。战场美术、按钮纹理、全身棋子形态仍不完全相同。
- 广告仍为显式开发模拟，未接真实广告位。开发者工具通过不代表手机实机、微信开发上传、审核或生产发布。

## 后续架构建议

下一步应将技能拆为可组合的命中、持续状态、召唤、位移和死亡触发处理器，统一由事件调度器执行。每种机制增加来源和完成状态标记，再用原版逐帧战报作对照用例；这样可以逐项收敛差异，避免继续在战斗循环和弹窗里堆条件。
