# 1.0.8 前两章技能触发与表现

## 范围与来源
现有配置 chapter <= 2 的 11 名武将：甄姬、许褚、夏侯渊、赵云、黄忠、太史慈、张飞、周瑜、关羽、颜良、黄月英，共 44 项已知技能。按 expedition-data.js 的阶级、冷却和说明恢复本地行为，不声称与未取得的原服务端时序完全相同。其他武将沿用原主技能流程。

## 修复
上一版只按武将分类通用命中特效，且模拟器只处理主技能，所以冰封、暴雪和多数后续技能没有触发；太史慈火箭属于被动，未进入主动特效分支。

- hero-skill-config.js 以稳定技能 ID 配置参数；hero-skills.js 独立处理冷却、选敌、主动、持续与被动触发。仅使用当前阶级技能，未解锁技能不参与战斗。
- 冰封冻结三秒并逐秒伤害；冰星范围伤害减速；暴雪持续施法、可被控制中断；辉煌冷却光环不叠加。
- 太史慈火箭附加伤害与火焰箭迹；骨隐三次普攻触发位移和临时闪避；速射临时攻速；死契治疗与累加攻击。
- 补齐前两章范围伤害、连击、嘲讽、斩杀刷新、沉默、穿透、临时护甲、驱散、群体治疗、撕裂、吞噬、死亡爆炸和多重施法等规则。
- 真实 ability / status / damage 事件携带技能身份，视图按事件绘制冰晶、冰刺、火柱、光束、护盾、斩击等 37 类配置映射。主被动光环不强制反复播放动画。
- 太史慈保留人类弓手模型，身体高度比例 0.78 排除大弓占据的包围盒；按甄姬相同身体高度归一化，武器允许越出格子。
- 发布 PNG 压缩搜索由 speed 3 改为 1，保持原模型分辨率、颜色预算和完整动作帧。

## 验证
- 148 项测试通过，包括全部技能配置与主动触发覆盖、阶级隔离、冻结逐秒伤害及行动阻止、驱散/护甲到期、撕裂叠层/到期、斩杀刷新、死亡被动、多重概率与持续施法中断。
- 模拟器逐项创建 37 类专属轮廓无异常；实际 expedition-combat 战报播放 35 秒、213 事件完成，记录冰星、冰封、暴雪、骨隐、速射、死契等，运行错误为空（evidence/replay-result-108.json）。
- 静态验收截图 evidence/freeze-nova-108.jpg 展示真实战报对应的冰晶/冰星，暂停的是特效补间而非游戏渲染；模型并排截图 evidence/models-108.jpg。
- 21 套发布模型的帧序、逻辑骨骼、图集边界及人体像素密度验证通过。源码同步检查通过，包体积 31,381,368 字节，主包 2,328,591 字节。
- 所有页面测试使用不落盘的隔离模型；还原后真实玩家状态未变化。
- 模拟器结果不替代手机端性能和视觉验收；尤其大量范围技能同时释放仍需实机反馈。

## 后续设计建议
将剩余章节逐步迁移到相同技能 ID 调度表后，删除旧 primarySkills 兼容分支，避免两份规则漂移。再将沉默、减速、嘲讽与持续施法统一为可取消的状态实例，以减少不同控制组合的边界维护成本。此轮限定前两章，不扩展后续章节未知规则。
