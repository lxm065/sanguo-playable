# 挑战段位UI制作清单

当前工程实际配置为11档，尚未核实原版完整段位体系：

| 徽章 | 档位 | 星数 | 积分起点 |
|---|---|---|---|
| iron | 黑铁1～5 | 1～5 | 0、50、100、150、200 |
| bronze | 青铜1～5 | 1～5 | 250、300、350、400、450 |
| silver | 白银1 | 1 | 500，当前最高档 |

只需生成3枚基础徽章。推荐透明PNG，512×512，主体居中，四周留约8%空白；不带文字、星星、积分、背景板。建议黑铁采用深银灰金属、青铜采用铜金色、白银采用冷银蓝色，保持相同轮廓和光照。可使用原创盾徽、剑翼或冠饰。

程序单独显示星星、段位名、积分。菜单、大厅、结算读取同一段位算法。资源接入配置为 game/play/challenge-config.js 的 settlement.badgeImages，键为 iron、bronze、silver；当前为空，仍使用占位徽章。将资源放入 game/skin-assets/ranks 后配置相对路径即可替换。
