# 1.0.11

- 火箭飞行与命中特效分离，命中只播短促火焰，不再在敌人位置重播箭矢。
- 反旋概率判定后发送一次独立 ability 事件，许褚自身播放原生 Cleave 刀光旋转；范围内各敌人的扣血不再重复生成震地效果。
- 冰封在独立战斗层跟随被控目标，死亡/驱散移除；冰封持续伤害不再生成重复冰块。冰星加大可读性并采用独立播放时长。
- 所有原生动画从素材就绪开始计时，修复加载耗时吃掉动画的问题。
- 新局福利进度从配置起点恢复，读档不重置；新局递增广告票据序号，防止旧回调重复发奖。
- 158 项测试通过；实际技能回放 231 事件含冰星、冰封、反旋，未记录异常。静态冻结截图采用纯内存局延长显示，仅用于画面验收。
- 完整独立技能规则覆盖 11 人：甄姬、许褚、夏侯渊、赵云、黄忠、太史慈、张飞、周瑜、关羽、颜良、黄月英。其余武将仍属旧主技能/通用攻击兼容，不算完整表现覆盖；被动属性技能并非每项都有独立粒子。
- 后续建议将弹道、命中、持续状态及角色动作显式拆成四类配置，避免弹道资源误用于命中；目前通过 impactMap 已隔离最直接的问题。
