# 1.0.213 武器专属技能

1. 青龙偃月刀：关羽击杀后跳劈，额外对死亡格周围一格（含斜角）造成55%攻击力真实伤害，不连锁追斩。原近战普攻溅射保留。
2. 虎痴镇阵从虎贲护臂迁至虎卫坚盾，仅许褚生效。敌伤将使生命降至30%及以下时，本次即开始吸收50%敌伤，持续3秒，冷却15秒。金色全身圣盾；不吸收自身扣血。护臂原基础效果保留。
3. 修罗面甲：仅太史慈普攻命中后25%概率追加放大的火焰箭，100%攻击力物理伤害，不暴击、不递归触发普攻追击。
4. 养由弓：仅黄忠连续命中相同目标，每次使后续普攻增加5%伤害，最多30%。首发无加成，换目标重置，闪避不叠层，技能不吃此加成。
5. 运筹帷幄从离魂羽扇迁至破军令，仅周瑜生效。释放本体技能后全体存活友军获得下一伤害技能+10%，不叠加；范围、多段、持续技能全部伤害段按施法时倍率结算。治疗、无伤害技能不消费；不作用于装备追加伤害。头顶直接复用用户提供的嗜血图标，消费或死亡时移除。

## 实现与验证

weapon-exclusive-config 统一数值和表现资源，weapon-exclusive 负责战斗快照及事件，weapon-exclusive-view 消费事件。装备说明、资格名单、战斗与详情保持一致。没有迁移或重写玩家装备存档。

测试覆盖资格迁移、低血阈值、到期冷却、自损、追斩范围真伤、火箭概率、黄忠叠层、周瑜多段快照、图标消费和死亡清理。真实模拟确认周瑜全军发放/消费，以及关羽对一万护甲仍造成55%攻击力伤害。尚未完成真机动态观感验收。

## 后续结构建议

战斗循环目前同时处理本体、天赋和装备回调。后续新增更多专属技能时，建议统一 beforeCast/afterCast/onHit/onKill 的事件接口，并将一次施法的伤害快照作为独立数据对象，使延迟弹道、持续伤害、被动伤害与一次性增益的消费规则集中管理，避免跨模块添加条件分支。
