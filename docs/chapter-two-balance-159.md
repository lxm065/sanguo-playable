# 第二章难度调整（1.0.59）

第二章通关切换时会重置局内等级、阵容和装备。旧逻辑却从独立敌池抽取二阶武将，且从首节启用装备，首节尾王使用默认四阶加三阶护卫，造成开局成长与敌方强度错位。

本次第二章复用第一章同阶段的候选池、解锁节奏、敌人数、配装起点及随机种子。第一小节不配装；首王保留太史慈身份，改为三阶及三名二阶护卫。后四节使用对应第一章的尾王与护卫，补齐章节标题。敌方生命与攻击倍率在参考曲线上乘以 1.10；该数值不等于胜率或总难度增加 10%。

第一章及第三章之后保持原规则。未改变奖励、存档协议及已保存的待领取战报。第二章已经在途的玩家从下一次生成战斗起使用新曲线。

配置入口：game/play/chapter-difficulty-config.js。战斗与详情统一读取 chapter-difficulty.scale，避免两个公式漂移。后续章节应基于同一策略扩展，并用真实路线通关率校准英雄技能造成的差异，不建议继续增加独立且跳过阶级筛选的敌池。

验证：24 项平衡和远征测试、31 项章节和战斗回归测试通过；65 组对应阶段阵容及属性对比；微信模拟器真实模块内独立第二章开场演算胜利、47 个事件、原玩家存档不变。尚未进行第二章全路线人工游玩及真机通关验收。
