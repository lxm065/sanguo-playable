# 1.0.186 典韦一技能

此前仅有旧主技能150%攻击、1格范围伤害与通用攻击表现，首次冷却9秒，没有专属抛起动效。

本次改动：
- 首次冷却配置为0，首轮优先对最近的可选敌人施放，首轮可越过近战距离；后续恢复近战距离和原9秒冷却。存活且未被控制、有可选敌人的正常开场0秒出手，满足2秒内释放。

- 动效时长匹配现有攻击前摇，随倍速缩放；离场、重复抛起均恢复模型位置。
- 仅技能事件带专属动效，普攻不触发抛起。
- 所有开场规则、动效高度、帧及资源参数在game/play/dianwei-skill-config.js配置。
