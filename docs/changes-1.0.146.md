# 1.0.146 修复视频回调不再减难

原因：旧循环回到lastClearedDifficulty或legacyAnchor后，再次视频仍选择相同值，只缩小后续步幅，当前生命攻击倍率没有下降。初始系数1下限也使第一场失败无法下降。

用户已明确允许连续失败时突破初始下限。现仍优先回到最近通关难度；若锚点已经不低于当前难度，视频改为当前系数乘retryFallbackMultiplier=0.85。无通关记录且初始就失败同样允许减难。低于初始值的状态正常保存，查询、开战迁移、重载不再抬回1。进度安全下限0.1、生命攻击倍率下限0.01，防止旧倍率下限提前抵消回调。第一阶段沿用既有保护规则。

实际下降后仍把与失败点的差距分4步恢复。默认15%是可配置减压强度，不宣称经过胜率标定或看一次保证获胜。用户截图不能提供其完整装备、天赋和战报，验证使用独立相似五人混阶阵容，不冒充复现真实存档胜负。

新增测试直接检查prepareBattle输出的敌军生命、攻击连续下降，而非只检查difficulty字段；覆盖阵容不重抽、低于初始值后读档不反弹、旧版已两次视频存档可继续减难、失效与重复广告不生效、写盘失败回滚。

旧版已经观看的视频次数不会在更新时凭空重放或重复扣减；更新后成功领取的下一次视频立即使用修正规则。
