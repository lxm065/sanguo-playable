# 1.0.139 已知失败难度分四步回升

将视频后单纯步幅减半，改为按已知失败难度与最近通关难度的差距分成4份。视频回调后每次通关增加其中一份，4次增幅后回到此前失败的公共进度系数。例如113.4已通关、117.6失败：视频回113.4，随后114.45、115.5、116.55、117.6。增长值由实际已知区间决定，不再手填固定减半后的增量。

同级回调缺少正差值时，把当前步幅分为4份作为继续探索的增量；最低浮点步幅0.000001仅防止数值停止增长。回升4次不等于强制第4次失败，玩家培养、阵容、关卡类型及技能克制仍影响结果，不改判战斗胜负。跨类型保持普通、精英、Boss不同倍率。

首轮缺少失败记录，暂沿用0.04经验初值，尚未达到所有阵容四次遇阻的标定要求。此次离线抽样是固定敌阵的增长轨迹，不是完整连续路线通关模拟：2种培养组×3类关卡×2种增幅×5个增幅位置×16种子，共960场。普通关0.04在两组第四次仍16/16胜；0.10第四次弱培养0/16胜、强培养12/16胜；Boss两组初始均0/16胜。样本说明单一增幅不足以覆盖不同培养与关卡类型，不能将0.10直接认定为已验证的首轮参数。

证据：tools/check-four-step-initial.cjs、evidence/four-step-initial-trajectory.json。模拟工具仅供离线使用，不进入小游戏包，不增加开战等待。后续应独立标定首轮类型强度及培养估算，再统计真实路线的首次失败位置分布。
