# 1.0.181 后期章节难度与配装

每章第一阶段保护保持原样，下列策略从第二阶段生效。

| 策略 | 第1～3章 | 第4章起 |
| --- | --- | --- |
| 连胜第4次增幅 | 20% | 30% |
| 连胜第5次增幅 | 40% | 60% |
| 连胜第6次起增幅 | 80% | 120% |
| 视频减难后恢复原失败难度 | 3次胜利 | 2次胜利 |
| 普通主力配装覆盖目标 | 50% | 65% |
| 精英主力配装覆盖目标 | 75% | 90% |
| Boss主力配装覆盖目标 | 50% | 65% |

增幅乘以上次通关难度；前3次胜利沿用原规则。恢复期间独立计步，不叠加连胜加速。连续视频继续保留原失败目标。旧档恢复周期按已完成次数迁移，不立即改变当前难度。

配装人数向上取整，普通和精英补足目标而不移除既有装备；每人最多一件，低级援军不配装。最终敌阵统一补足覆盖，避免章节映射、扩编稀释。已锁定关卡不重抽装备，后续新关卡生效。装备参与实际战力评估。

配置入口：enemy-win-growth-config.js 的 chapterPolicies、enemy-equipment-config.js 的 laterCoverage。章节策略由 enemy-cycle-policy.js 统一解析；最终配装由 enemy-equipment-coverage.js 处理。

回归覆盖60章普通/精英/Boss增幅与恢复次数、旧恢复存档迁移、实际敌阵装备覆盖及锁定稳定性。后续可将章节策略集中为同一个难度配置对象，避免成长与配装的章界配置漂移。
