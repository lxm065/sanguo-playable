# 1.0.138 视频后缩小增长步幅

保留视频回到最近通关难度的规则，同时缩小之后每次通关的增长步幅。本章初始步幅0.04；每次有效战败视频回调后乘0.5，因此依次为0.02、0.01、0.005。最小0.005保证仍可缓慢递增。通关不会恢复旧的大步幅；跨阶段、存档重载继续沿用，新章或重开本章重新初始化。

普通关例子：基准100，类型系数1.05，已打赢进度1.08（113.4），下关进度1.12（117.6）失败。视频回调至1.08，并把增长步幅0.04改为0.02；再次获胜后进度1.10（115.5），之后再获胜才到1.12（117.6）。如再次遇阻视频，回到最近通关进度并把后续步幅进一步缩至0.01。

旧存档未保存步幅时，以已领取的视频回调次数恢复步幅，完成后写入本局状态，重复加载不再折半。基准战力不重新计算，第一阶段保护、敌阵人数等级配装限制和待领战报保持。视频取消、过期、重复回调由现有奖励事务拒绝；写盘失败回滚难度与步幅。

参数集中于enemy-light-balance-config：winIncrement、videoStepMultiplier、minWinIncrement。循环状态与静态战力估算继续分离，不增加运行时模拟或等待。

参数验证边界：0.04初始步幅、0.5视频步幅倍率和0.005最小步幅均为经验初值，尚未经过多阵容实战平衡标定。自动测试仅验证规则、存档和事务，不证明这些数值合理，也不证明目标胜率已实现。
