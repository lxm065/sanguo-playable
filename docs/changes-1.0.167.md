# 1.0.167 暴击飘字单行修复

原因：原伤害文字框宽度260，使用通用文字控件默认换行与裁剪。暴击大字号加前缀后宽度不足，产生前缀、减号、数字分行。

修复：战斗飘字宽高改由combat-text-config配置（520×80），明确禁用换行并采用SHRINK溢出策略。大数字整体缩放，保留暴击及斩数的加粗描边、弹跳。仅调整表现，不修改伤害或技能规则。

验证：9项专项通过，覆盖四位、大额伤害与七斩前缀。真实模拟器Label确认enableWrapText=false、overflow=SHRINK、width=520。截图中“暴击！ -2143”和“七斩 -123456789”均完整单行。

证据：evidence/combat-text-1.0.167.png。

后续建议：对所有短时战斗提示统一采用显式单行/换行策略；通用段落控件继续保留换行能力，避免全局改动误伤图鉴和说明文本。
