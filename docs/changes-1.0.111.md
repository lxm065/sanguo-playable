# 1.0.111 击杀播报与章末结算

- 五杀素材 feedback/5.png 核对为“五子登科”，不是首杀图片。错配源于音频排队但横幅立即显示，以及非全场首杀的个人第一次击杀也被映射成首杀。
- 音频队列现在保存同一次击杀的类型、数量和双方武将。微信 onPlay 触发时显示对应横幅，排队中的低阶播报被高阶替换时同步替换视觉数据。静音或无音频能力仍立即显示正确横幅，播放错误有视觉降级；新战斗和切后台清理队列及横幅。远征与多人共用此路径。
- 只有全场第一起有效击杀显示首杀。其他武将个人第一次击杀、连杀超时后的第一次击杀不再显示首杀。五杀沿用原五杀图案和 penta_kill 语音。
- 主公升级提示配置 showCells=false，保留原气泡、角色和顶部人口提示，不创建棋盘空格描边。
- chapter-final-reward 统一判定正式战斗、胜利、最后小节和首领节点。最终胜利不生成选将候选；视图自动完成本场领取并进入远征首页的永久通关奖励。旧待领取选将战报也直接跳过，不增加武将；非章末关卡仍选将，训练及失败不受影响。写盘失败保留战果供重试。

## 验证

- 509 项自动测试全部通过。新增队列五杀图文同源、最高档连续覆盖、首杀去重、静音/错误、六十章最终关、旧战报和事务回滚覆盖。
- 模拟器：升级提示绘制时棋盘定位调用为 0；章末战果自动清除，进入 home，保留永久 sectionReward，选将按钮数为 0，武将数量不变；真实玩家存档已恢复且未改变。
- 手机扬声器的实际播放延迟仍以真机试听为准，自动测试验证的是回调时序和资源对应关系。

## 架构建议

后续应让所有播报只消费统一播报事件，由音频调度器控制开始时刻，避免再次出现视图自行播放横幅的第二条路径。章节结束、普通战果和永久奖励已用独立判定隔开，可进一步把奖励类型判定收敛为单一领域策略，减少视图与领域各自判断造成的遗漏。
