# 1.0.81 战斗提示与路线难度

- 暴击保留真实伤害计算；同攻击者、目标、状态对照测试确认暴击高于普攻。技能伤害增加文字前缀，护盾吸收仍单独显示。
- 第一章第二至第五节按实际上阵阵容计算：敌方人数增加 1 或 2、总等级增加 3，第二至第四节不带装备。首节教学规则保留。
- 各章各节地图首次生成后保存在 fixedRouteEvents，重开/重进复用；在途旧地图保留。
- 逐节点 routeResources 记录正常视频收益预算，跨小节累计、跨章重置。普通及首领按二阶奖励，精英按装备，宝藏按全领。商店按金币 50% 购买二阶武将预期且受商品数限制；泉水按一次二阶单位合成质量估计。这些是本地可调策略，不宣称原版精确公式。
- 高等级视频概率的额外收益、玩家具体商店消费决策未逐次模拟；预算作为稳定基线，章节经济、永久装备与天赋仍有独立成长项。
- 后续章节等级下限及属性适配参考路线预算，首遇冻结倍率；视频重试保持阵容并降低生命、攻击和装备强度。
- 旧存档缺失的过往小节路线按历史胜场兼容估计，从当前小节已完成节点开始精确记录。
- 测试证据：evidence/tests181-final.log；新的规则覆盖在 tools/test-rules-181.cjs。
