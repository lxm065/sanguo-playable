# 1.0.66 玩法修正（2026-10-08）

## 解锁与次数

第三章通关预告改为疯脸（存档ID 7208，对应三国表现修罗面甲）进阶。实际进阶门槛原本就是通关第三章，本次修复首页错误地继续显示下一主公的问题。不会直接发放+8强化。

倍速从初始开放。新旧档均只追加一次10次，永久标记防止重载、重开章节重发；保留旧有次数。视频或分享补充20次，分享沿用微信离开返回软校验，不声称核验好友实际接收。同一场战斗扣一次，备战切换不扣，开战失败时整个事务回滚。零次显示+20入口与剩余次数。

## 主公技能

袁绍概率按用户核对从30%修为1/3。每次正式开战播放袁绍卡牌与对白，再播放成功装备放射光、名称或失败头像对白；结果播完才启动战斗时间轴。继续使用已持久化回执，不在特效中发奖。曹操也共用该卡牌表现。演武和多人挑战不触发固有主公技能。

## 敌人规则与视频重试

原规则：第一章及未单独配置章节使用阶段线性倍率（0.7起，每阶段+0.05，最高2.2）；第二章使用五小节曲线、阵容平均阶级适配、固定节点±3%随机及失败每次6%整体属性减免。

新规则：保留章节人数、阶级和首领编排，删除失败触发的整体属性减免。按当前人口及历史胜场估算正常视频资源：普通战斗占70%，每次普通胜利领取2阶武将，以三合一质量折算参考平均阶级；精英装备预算为每胜场0.3件。此比例是本地可调估计，并非完整模拟玩家的所有广告行为。

参考阶级与装备预算超过敌阵时，增加至多35%的装备增益，并附加节点固定的0～12%随机增益。首节原本无装备的敌阵只给一件约12%强度装备，使早期重试也有装备调节空间。规则集中在enemy-budget-config.js。

首次开战保存当前节点敌阵和基础属性倍率。战败后只有成功领取视频祝福才增加重试辅助：装备增益乘0.4，再次辅助继续衰减，最低为原增益的8%。装备ID、图标、敌人身份、数量、等级、位置和基础倍率均保持。普通失败不降装备强度；重复视频凭据不重复降。重载使用同一快照，不重抽。

战斗仍使用真实模拟器，不强制胜利。极端不足的玩家阵容可能在降低装备增益后仍无法取胜，后续应根据实际通关率校准章节基础曲线和装备辅助幅度。
