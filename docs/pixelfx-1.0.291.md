# PixelFX 首批动效试用 · 1.0.291

本次接入普攻命中火花、枪刀轨迹、武将成功升星光效。远征沿用原事件入口；挑战、刀锋竞技和英雄副本共用出手入口，统一获得武器轨迹。法术、箭矢、专属装备技能与伤害、冷却、命中时刻、奖励事务保持原执行逻辑。

## 配置与资源

- `game/play/pixelfx-config.js`：总开关、最多同时存在16个新增效果、武器映射、颜色、尺寸、时长和升星表现。关闭 `enabled` 后回退既有表现。
- `tools/pixelfx-export.config.json`：源效果、配色、导出帧率、截取时段、透明阈值和资源预算。
- `game/play/effect-manifest.js`：合并旧原生模型与新离线图集的索引，保留两套可追溯来源。
- `game/play/native-effects.js`：共用缓存、长方形帧、独立锚点和单一计时器；最长边决定显示尺寸。图集左上原点转换为Cocos的底部锚点，旧正方形资源维持原尺寸。
- `source-assets/pixelfx`：仅包含重建本批资源所需的23个上游代码文件和来源摘要，不随游戏发布。

新增4张图集共224,423字节，RGBA8888展开共2,362,800字节，不含mipmap与驱动额外开销。每张图集最长边不超过1024像素；导出预算为PNG不超过256KiB、纹理不超过3MiB。导出器按原始RGBA拷贝透明像素，避免透明底合成时重复乘alpha导致变暗。

重建命令：`node tools/export-pixelfx.mjs`。上游 [patch-gg/pixelfx](https://github.com/patch-gg/pixelfx) 为0.3.0，具体文件SHA256见 `source-assets/pixelfx/provenance.json`。MIT声明随游戏保留在 `game/play/third-party/pixelfx-LICENSE.txt`；没有引入其画廊字体、默认人偶或英文升级文字。

## 验证

专项测试覆盖图集边界、长宽比和锚点、旧帧兼容、帧缓存复用、加载失败重试、离场后异步回调、节点数量上限、倍速清理、开关回退、挑战出手入口和成功升阶条件。

全量命令 `node --test tools/test-*.cjs`：1033/1033通过，见 `evidence/pixelfx-1.0.291/tests.txt`。

首轮发布包总计31,381,452字节，超过项目配置的安全预算55,244字节，因此未上传该产物。后续仅将发布副本的非透明背景JPEG质量从42调整为36；原始美术资源不变。构建与开发上传分别以最终报告和回执为准。

模拟器验收脚本 `node tools/run-pixelfx-runtime-qa.cjs` 只在当前版本生成目录临时增加探针，使用独立视图、真实武将与同一Cocos播放器左右对照。截图由开发者工具官方 `simulator_screenshot` 接口获取，避免当前引擎画布临时UUID被误作文件路径。探针结束恢复入口并移除临时脚本；报告加载效果、节点清理和玩家状态不变。此次保留12张抽帧截图，其中部分帧受到账号会话弹窗遮挡，对照样张选用无遮挡帧。该对照不替代手机帧率、发热或完整战斗实机验收。

最终构建：主包3,196,072字节，总包31,270,723字节。微信CLI开发上传成功，目标AppID为 `wx7a597ac02546773f`；微信回执主包3,241,419字节、总包31,316,021字节。发布副本中4张新增图集共53,989字节。上传日志、回执、文件摘要和验证结论见 `evidence/pixelfx-1.0.291/`；开发上传不等于审核、正式发布或真机验收。

## 后续演进

本轮将可复用武器表现集中到配置与共用播放器，避免各模式再复制一套动效。后续可根据实机峰值绘制量增加按优先级降级和节点复用；先测分配和绘制开销，再决定是否引入对象池。大范围雷火效果应在单独批次对齐真实技能命中点与范围，并验证遮挡、分包、纹理和同屏预算。
