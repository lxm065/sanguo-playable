## 缺少原版依据，单独配置的部分

所有参数集中于 `game/play/solo-challenge-config.js`，不藏在界面回调中。

1. **刀锋完整经济**：开局100金币/3生命/3基础人口、3次初始选兵、12胜或3败结束、每轮100金币及胜利50金币、敌阵数量与成长、商品价格、刷新30金币、人口150起每次递增50。这些是本地可玩参数，不是原服恢复值。
2. **秘典收益**：每胜2本、终局基础1本；放弃不发奖。本地星数每胜+1，未接原服排名、赛季、对手匹配或真人对战。只恢复原表段位显示。
3. **入场、每日次数与扫荡**：原服返回 freeCnt/adCnt/ticket/playCnt 等动态状态，现有样本不够。新模式暂为免费进入，不扣邀请函、不套用猜测的每日次数；竞技和副本扫荡、付费/排名奖励未冒充实现。
4. **副本路线与敌人**：原表提供九节节点模板ID，完整随机地图和敌阵算法未恢复。本次使用已有本地路线模板，并执行可确认的特殊规则；360条配置可进入不等于360个副本已在原服/手机逐一通关验收。
5. **副本奖励与次数**：本地通关500钻石+随机蓝装2碎片，首次奖励乘2；未使用猜测的入场券或日次数。奖励生成、首次/重复奖表、精确刷取分布待补证。
6. **主公模式差异**：继承生命/初始金币、刘备人口、董卓商人与首领装备、曹操战前征召、袁绍战前装备与孙权合成返还/泉水升级。概率使用本地策略；孙坚仅开局赠装，祝福装备无限成长、主公觉醒阶级的模式效果、刘表两蓝换紫尚未接入新模式，不把它们算作完成。
7. **战斗与养成口径**：复用现有本地英雄、技能、装备及羁绊执行器；新模式未套远征天赋/VIP/永久装备进阶加成。原版各模式是否共享这些加成未完成实测。
