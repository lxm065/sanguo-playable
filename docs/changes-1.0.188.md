# 1.0.188 张飞阵亡姿势与典韦翻滚抛掷

## 实现
- 张飞原正/背面死亡帧容易呈现悬空后仰；改用包内现有侧倒帧（e/w），在0.65秒内收尾，0.42秒开始淡出，保留左右朝向。其他英雄不变。
- 典韦一技能搜索全棋盘其他空格，优先向远离施法者方向抛出；其他位置全部占满时才原格落下，死者所在格可落地。
- 起飞时预占落点，避免多名典韦争用同一格；飞行期间暂停被抛目标的主动行动，落地后继续。
- 目标平移与身体上抛共用事件时长，身体在空中旋转360度，血条不翻转，落地恢复原角度。
- 落地时才按新位置读取1格范围内敌人，保持150%攻击倍率。典韦首次优先释放与后续9秒冷却保持不变。
- 死亡、退出、重复施放时统一清理位移和翻滚，恢复模型本地位置并对齐已结算落点。

## 验证
678项回归通过。新测试穷举1024种棋盘占位，覆盖无空位、仅剩一空位、尸体格、多次抛掷不同落点、落地范围更新、整圈旋转与退出恢复、张飞独立死亡配置。

证据：evidence/toss-death-1188-tests.log、evidence/zhangfei-death-before.png。张飞姿势调整依据包内死亡帧检查；真机视觉验收仍需确认。

## 配置与演进
落点距离和翻滚参数集中在dianwei-skill-config，张飞侧倒和淡出时序集中在death-view-config。后续投掷技能应复用落点预占/落地结算模块，避免各自在表现层移动模型而遗漏真实棋盘位置。
