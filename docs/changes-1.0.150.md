# 1.0.150 持有资源阵容基准

- 第二阶段起，人口内的参考阵容由全部持有武将和远征装备计算，忽略实际部署及装备归属。人口基础人数不随少上人而下降。
- 共用静态属性评分，包含培养、已激活羁绊、合法配装及已实现专属技能的近似收益。束搜索和配装候选均受配置限制，不调用战斗模拟；这是静态最强估算，不保证全局最优实战阵容或固定胜率。
- 敌军等级上限取全部持有最高等级；Boss最高等级人数最多比玩家同级数量多1，玩家数量按人口封顶。仅持有一级武将时沿用最高阶配额优先的人数保护。
- 普通/精英的等级分布、援军均参考同一阵容。全员已达玩家最高级时不再为了精英区分而越级；差异继续由人数、装备和既有系数体现。
- 第1阶段保护保留。每章第2阶段首次开战才保存战力基准及参考阵容；已有本章基准和当前锁定敌阵不重算。新关等级配置使用新参考，新的战力基准在新章/重新开章后建立。
- 装备每实例一次、每人不超3槽，评估不修改真实阵容、站位、装备、随机种子和存档。视频回调和四次恢复目标不变。

架构：combat-power 提取基础评分，player-combat-context 共用纯状态培养快照，strongest-team 独立负责受约束候选选择和只读缓存。后续若继续扩展动态技能评估，建议提取按技能配置注册的评分适配器，以离线战斗样本校准；避免将模拟器重新接回实时开战路径。
