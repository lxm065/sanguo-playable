# 1.0.198 保护期逐关总等级递进

每章第一阶段首战总等级1，后续普通、精英及Boss统一不超过上一场实际通关敌军总等级加1，也不超过人口内最强合法玩家阵容总等级减1的尾王预算上限。当前玩家阵容突然升星不会导致敌军跳级。关卡数不足时Boss不会为追满预算而跳级。

敌方人数、逐名等级上限、裸装、无援军、保护期属性倍率以及单个一级最低战斗例外保持原样。总等级预算达到玩家上限后停留，玩家后续成长时再从上一场实际值最多加1。

enemy-opening-progress.js记录实际锁定敌阵的通关总等级，在正式领奖事务中保存。失败、训练、非战斗事件、同节点重复结算不推进。跨阶段不使用此进度，重开章节随远征数据清除；读档可继续。旧档缺少记录时按已完成战斗数保守回退，避免读取当前高等级阵容直接跳级。

enemy-opening-config.js的progression.initialTotal和maxIncrease分别配置起点及每关增幅。保护策略版本升为4，旧保护期快照一次迁移，待领取战报不重写。

验证60章实际开战与领奖链路、混合类型路线、每次总等级增幅、尾王预算上限、突然升星、读档、重复结算和阶段边界。阵容预算上限与通关进度分别由enemy-opening与enemy-opening-progress负责，减少跨模块重复计算。
