# 寻敌可达性修复（1.0.209）

最近敌人被占位包围时，原代码找不到进入射程的路径便原地等待，即使其他敌人可以接近。本次共享 approachStep 先保留首选目标路径；仅在失败时依照原寻敌顺序寻找其他可达敌人并移动。

- 基础战斗和远征战斗复用同一规则。
- targeting-config.fallbackWhenBlocked 控制回退，默认启用。
- 有效嘲讽禁止改选；技能释放与指定目标规则不变。
- 活单位仍阻挡通行，不穿人、不重叠，全部堵死时等待下一次寻路。
- 不引入随机数，保持战斗可重放。

专项验证覆盖完整绕行至攻击距离、所有出口封锁、嘲讽、配置关闭、死亡后释放占位及重复结果一致。

长期优化：若未来单位数量明显增加，可将多个不可达目标的路径搜索合并为一次可达区域搜索；目前首选目标可达时不会进行额外搜索。

验证：738 项测试通过，22 项发布模型检查通过，微信开发版 1.0.209 上传成功（exit 0 / √ upload）。尚未真机验收或正式发布。
