# 1.0.156 分叉行军地图

- 每章每节只有一个普通战斗起点，起点分出 2～3 条出路。
- 后续非终点节点随机连接下一层 1～3 个节点，所有节点可达且可以走到唯一终点 BOSS。
- 整张小节地图的精英、商人、泉水、宝藏总计随机 10～14 个，至少包含每类一个；普通节点填充其余位置。
- 每条完整路线仍为原有 18 个节点，以保持章节进度和排行榜计分单位不变。
- 分叉、节点位置和类型以章、节保存到 branchRoutes。重开、重载、章节重玩不重新抽取。
- 进行中的旧小节保持原图，新小节或尚未开始的小节启用新图。
- 参数集中在 branch-route-config.js；生成和连通性快照由 branch-route.js 管理，视图及实际入口共用 route-graph.js。
