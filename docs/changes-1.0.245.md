# 1.0.245 大阵容交互开销优化

- 属性计算跳过未由当前队伍穿戴的背包装备。一次单侧阵容快照复用羁绊和装备定义解析；缓存不跨快照，不保存动态战斗属性。
- 开战不再先创建结算模型再销毁重建；战后不再装配本就隐藏的死亡单位模型。存活单位、手牌及底部操作仍走原有绘制入口。
- 八人上阵、120件装备（24件穿戴）的本地基准：整队属性准备中位耗时约1.279ms降至0.328ms；与修改前逐字段一致。纯Node计算测试不代表手机帧耗时。
- 完整测试833项通过；新增属性一致性、装备解析次数、实际战场入口模型创建测试；已有顶部/底部/开始按钮回归通过。
- 待真机验证：第五阶段主公8级以上的合成、首次属性点击、战后帧耗时。存活模型仍会随完整页面重建；建议后续将背景/HUD与棋子生命周期拆开，以UID及外观版本做局部更新，并增加真机帧耗时采样，避免为了预热制造新的帧峰值。
