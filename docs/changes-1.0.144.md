# 1.0.144：青釭剑·七进七出

- 仅装备青釭剑的赵云获得独立主动技能；重复青釭剑只生成一套释放状态。
- 默认开局发动、12秒冷却，每0.2秒随机选择一名可选中的存活敌人，共7次，每段100%攻击力物理技能伤害；数值集中在 `game/play/qinggang-config.js`。
- 每段重新选敌并高速切入空位；只剩一名敌人时允许连续斩击，敌人全部死亡则提前结束。
- 释放期间禁止普攻和其他本体技能行动，无敌且不可被敌方选为目标；统一伤害入口拦截范围、持续伤害、反伤，命中队列同时跳过控制附加效果。
- 复用现有刀光及粒子资源，位移和残影随战斗倍速播放，离开战斗沿用补间和效果节点清理流程。
- 图鉴移除该技能的待实现状态，保留青釭剑原普攻破甲效果。

验证：全量588项通过；专项覆盖随机七段、单敌、目标死亡、资格、重复装备、沉默、冷却、确定性回放及无敌结束后受伤恢复。补充反伤和在途攻击场景后专项5项通过。尚未进行开发者工具视觉或真机验收。

架构建议：当前无敌/选敌资格已抽取为公共策略，后续新增潜行、遁地和其他专属连击应复用该入口；继续将装备主动调度从 `equipment-effects.js` 的分支拆为技能注册表，统一冷却、目标选择和事件输出，避免每种装备分别维护保护规则。
