# 1.0.131 普通及精英难度回调

原因：新增敌军人数按比例复制高阶主力，再叠加路线升阶、配装、章节倍率，导致截图所示六人混阶队伍面对三名四阶和大量三阶。

调整：核心阵容保留我方等级分布，额外主力使用最低阶档位（enemy-stage-config.extraMainQuantile=0），随后沿用原升阶名额。普通属性折扣0.65、精英0.72，并乘sqrt(己方上阵数/敌方主力数)，人数比最低0.25、最高1。此折扣同时作用生命和攻击；人数、路线升阶配额、配装、低级援军不变。首阶段保护及尾王不参与折扣。全部参数可配置。

旧缓存通过策略版本8迁移；新版重复进入不会重复乘折扣；待领奖战报不改。

验证：546项测试通过。tools/check-balance-1131.cjs 使用第五章第二至五阶段最后普通/精英节点，各12个战斗种子，共96战；我方等级4/2/3/2/2/4，指定站位，每人7001和7202两件装备，默认天赋。调整前普通0/48、精英0/48；调整后普通48/48、精英36/48。属于固定假设的回归模拟，并非用户完整存档或全阵容胜率。证据见evidence/balance-before-1.0.131.json与balance-after-1.0.131.json。

架构建议：人数扩展、等级分布和属性补偿共同形成难度，后续应在统一遭遇预算内监控总属性与配置目标，配合多阵容多种子模拟，避免逐项增强后叠加失控。本次将压力补偿独立为enemy-pressure配置及模块，便于后续标定。
