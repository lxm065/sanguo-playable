# 敌军最高阶人数限制与旧关卡减难保留

- 修复普通、精英主力复制等级分布后，额外主力和升阶名额叠加突破最高阶人数的问题。生成计划和最终主力、援军共用 `enemy-highest-limit`。
- 第二阶段起最高等级不得超过玩家全部持有卡牌最高等级；最高阶名额使用人口约束后的持有数量加1。多余最高阶单位降一级，全一级队伍不能降成零级，改为限制人数。
- 旧第9版敌阵只修正等级，不重抽身份、站位、装备；已经结算待领奖的战报保持不变。
- 迁移旧敌阵时保留 `lightBalance` 已兑现的广告减难倍率及循环记录，不用章节原始倍率覆盖。旧战力折算分母保持锁定，避免降级后重新归一化把已获得的减难抵消。
- 参数集中于 `enemy-stage-config.highestLimit`；未来人数或等级规则应继续通过最终约束入口处理，避免主力、援军、首领分别漏限。
- 新增覆盖60章第二、四、五阶段三种战斗类型，以及旧8个四级降至最多4个、连续五次广告、重复迁移和待领奖保护的回归测试。
