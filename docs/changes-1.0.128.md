# 1.0.128 当前战力敌军生成

每章第一阶段普通与精英保护逻辑不变。阶段末首领固定五人，等级顺序二二二一一，首领带一件装备，四名副将固定随机选两名各带一件装备，无额外低级援军。随机使用节点种子，不消耗玩家随机序列，重进不重抽。

从第二阶段第一个战斗节点开始，基础等级取当前上阵平均等级向下取整，最低一级最高五级；空阵预览使用人口内最强候选。人数、路线递进、普通/精英升一级比例与属性倍率仍读取现有配置。首章第二阶段起也使用此统一生成流程，不再被旧首章总等级预算覆盖。

第二至第五阶段尾王均执行既有最高等级与精锐名额规则：我方最高加一且最高五级，精锐1～2名；我方已有五级时，敌方五级比我方五级多2～3人，受棋盘容量限制。低级援军平均等级减一并限制1～3级的规则保留。

属性适配改读当前阵容平均等级，敌方装备强度适配改读当前上阵者实际已穿装备数量；章节、天赋、装备进阶成长及既有配装覆盖率配置保留。策略版本5，旧敌阵缓存迁移同步更新等级和属性倍率。首次开战锁定当前遭遇，失败重试仍执行原减压策略，已结算待领奖战报不变。

536项测试通过，新增全60章固定首阶段尾王、第二至第五阶段多档玩家等级、每阶段首领配额、重绘随机稳定、新节点重算与重试锁定验证。首阶段固定阵容、当前队伍查询和尾王名额分别独立配置与实现。
