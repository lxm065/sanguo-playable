# 1.0.133 目标胜率校准

用户确认阶段曲线：第2阶段普通90%/精英75%/Boss60%；第3阶段85%/70%/55%；第4阶段80%/65%/50%；第5阶段75%/60%/45%。这是模拟目标，实际战斗仍按技能、阵容、站位和独立实战种子结算，不按目标直接改判胜负。

机制：首次正式开战采用当前阵容、站位、已穿装备、装备进阶、天赋树、常规天赋、羁绊与VIP上下文进行真实战斗预演，仅调整敌方统一生命和攻击倍率（0.1至8）。人数、等级、身份、位置、装备件数不改，第一阶段不参与。倍率锁入enemyEncounter，之后重试只沿用原减压，不重新校准；新节点重新校准。未校准的旧关卡第一次开战可校准，已保存战报不变。

enemy-winrate-config集中管理曲线、最多40个独立固定种子、最多11个候选倍率、5个百分点容差和倍率边界。Wilson区间在至少8样本后确认明显偏离目标时提前结束该候选。接近目标的候选使用完整样本。预演不读取或消耗实战随机种子，不挑选实际输赢种子。搜索不能保证所有战术组合单调；记录达标标志及偏差，同误差取较低倍率。

界面通过独立快照分帧预演，显示整军中遮罩，阻止重复开战与改阵；结束才与正式战斗一并落盘。预演异常、页面销毁或期间状态变化不写入快照。直接模型开战仍保留同步校准路径。正式战斗和预演统一使用player-combat-context，避免天赋装备漏算。首次开战会增加等待，设备性能影响时长，真机耗时尚待验收。

验证：553项测试通过；界面配置最终调整后6项专项测试再次通过。覆盖曲线、上下界、达不到目标时的偏差、同节点锁定、新节点重算、正式种子不变、阵容装备不变、教学/历史战报、同步与分帧一致、遮罩防重入和失败不落盘。

tools/check-winrate-1133.cjs使用第五章七人阵容4/2/4/3/3/2/4，裸装与每人7001+7202+7204并带三级进阶/天赋两组，第二至五阶段3类节点共24场景。每场景使用独立80种子验收，共1920战。23/24场景的校准样本落入目标±5个百分点；独立验收平均绝对偏差约7.6个百分点。培养组第二阶段独立胜率普通92.5%、精英70%、Boss62.5%。裸装第二阶段Boss存在0/100%跳变，目标60%无法命中，保留较温和100%样本值并标记未达标。详情evidence/winrate-1.0.133.json。桌面测试计算耗时1.7至13秒，部分测试并行竞争CPU；不可视为真机耗时。

架构收益：难度目标、搜索与战斗上下文独立于UI，分帧和同步共用搜索状态机。后续可扩展多战术统计与后台性能分析，避免再次依赖固定倍率反复调难度。
