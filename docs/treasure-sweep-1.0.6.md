# 1.0.6：宝箱动画、每日扫荡与通关奖励

## 功能
- 宝藏保持三份已保存候选：先显示三个关闭宝箱，再依次抖动、掀盖、光束和物品浮起，动画完成后开放选择/全要。动画只记录revealed，不发奖、不改候选；中途离开取消计时，重入使用同一候选。
- 通关第一章后首页开启每日10次扫荡，前3次免费，后7次完整视频。按用户明确回复，本轮不通过分享发奖。
- 最近通关的基础奖励保存为lastClearReward，扫荡复制快照；普通与双倍互斥。通关选择双倍也不会把双倍数量写成以后的扫荡基础奖励。
- 用户提供的奖图：暗灭7001碎片2、先锋盾7206碎片4、灵魂石7205碎片3、战鼓7202碎片2、散失7101碎片3、梅肯7211碎片1、钻石500。补齐最后一节通关奖励为此奖表，领取后重置下一章局内状态，并回到远征首页。
- 后续章节未提供独立数量规则，当前沿用最近已配置章节的基础奖表；今后可在sweep-config.chapterRewards覆盖。旧通关档没有历史奖励快照时使用该配置兼容，不声称恢复了原服历史随机结果。
- 首页通关后以主公配置的下一解锁章节显示头像与条件；第一章后显示通关第2章解锁袁绍。

## 事务与配置
- sweep.js负责每日额度、广告凭据、待领奖快照及原子发奖；sweep-view.js统一扫荡/通关奖励显示。
- 免费扫荡先固定奖励占一次额度，退出再进仍待领取；跨日不丢旧奖励。取消广告不消耗次数，跨日广告旧回调不消费新额度。
- treasure-animation.js只维护可取消的视图计时器，node-events负责候选与揭示状态保存。宝箱上下层来自原有event-chest.png的上40像素/下44像素拆分，原图保持不变。
- 长期建议将多个日限额能力（签到、扫荡、免费强化）统一日期键与时钟注入，但保留各自独立资格和结算事务，避免相互耦合。
