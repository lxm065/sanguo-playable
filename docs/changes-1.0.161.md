# 1.0.161 连胜增难与恢复状态修复

- 仅在当前难度低于恢复目标时使用视频后的小步幅；四次胜利增幅达到原失败目标后回到基础增长。旧档已完成恢复或无恢复目标时不再按历史视频次数永久折半。
- 正常模式读取实际胜利战报：耗时不超过战斗时限40%、本体存活至少80%、总剩余生命至少50%判为轻松；轻松连胜按当前系数8%、10%、12%、14%、最高16%增长，单次增量最多0.35。
- 险胜：本体存活不超过40%、总剩余生命不超过20%、或耗时至少战斗时限80%，增量0.02；其他胜利和缺失旧战报数据用原增量0.04。
- 恢复过程不被轻松加速打断；达到原失败目标后的下一次胜利才使用正常判断。失败、险胜/普通胜利及视频会中断轻松连胜，训练不影响循环。
- 保留章节初始战力、第一阶段保护、已锁定敌阵、广告凭据事务、难度上限3及倍率上限8；本次不调用额外战斗模拟。
- 阈值集中在 enemy-win-growth-config.js，属于可调初值，并非经过真机胜率校准，不保证恰好第四次失败。实际过关仍由战斗结算决定。
- 设计拆分：战报指标及增幅策略由 enemy-win-growth 负责，持久化循环与恢复由 enemy-difficulty-cycle 负责。后续应按真实战报观察轻松率、首次失败间隔与上限命中率，再调整配置；不将预演放回开战路径。
