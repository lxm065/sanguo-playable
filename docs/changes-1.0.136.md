# 1.0.136 初始难度高于战力基准

普通关原系数0.85意味着初始目标仅为记录玩家静态战力的85%，不符合默认逐步加难要求。类型系数现为普通1.05、精英1.20、Boss1.35；保留每次通关进度系数+0.04，战败有效视频回调后乘0.8。第一阶段保护不变。

每章第二阶段首次开战的战力基准不重新计算。新系数在下一次开战迁移当前敌阵倍率，人数、等级、装备和身份保持；本章已有视频回退与增长进度保留。迁移沿用历史减压次数快照，避免把新制视频回调次数错误叠加为旧式生命、攻击、装备削弱。旧待领战报不修改，仍可正常领取视频回退。

三个系数表示相对已记录基准的目标静态战力，不是胜率。实际战斗仍受技能、阵容和玩家后续培养影响；倍率安全上下限继续保留。后续平衡集中调整enemy-light-balance-config，不增加实时预演。
