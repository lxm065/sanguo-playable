# 马超护盾爆炸伤害来源修正

1.0.226 将生命值来源误解为目标；本版本按用户明确要求改为马超自身最大生命值。weapon-exclusive-config.js 的 7007.healthSource 改为 self，技能说明同步。

基础伤害 = 引爆时马超自身最大生命值 × 15%。不受目标最大生命值、马超当前生命或剩余护盾量影响。

现有魔抗公式保持不变：

有效魔抗 = max(-80, 敌方魔抗 - 马超法术穿透)

魔抗结算伤害 = 基础伤害 × 100 / (100 + 有效魔抗)

例如马超最大生命 10000，基础伤害 1500；有效魔抗 0、50、100、200 时分别为 1500、1000、750、500。之后仍执行通用天赋增减伤、格挡、减伤、护盾吸收及取整，因此不是必定扣除相应生命。负魔抗会放大伤害，当前统一下限 -80 最多放大到 5 倍。

保留蓄能 2 秒、破盾取消、消费剩余盾量、周围一格范围及原特效。测试覆盖当前生命极低仍按最大生命结算、不同敌人生命不影响伤害、法穿、正负魔抗及实际战斗。

重构建议：魔抗公式目前由普通命中和装备伤害各自调用，后续应抽取统一的伤害计算函数，保留现有数值语义并以交叉测试防止重复减免或公式漂移。本次通过既有配置完成修正，避免扩大改动范围。
