# 1.0.160 武将点击卡顿

发现：备战详情每次重新查询敌军并准备整场属性，敌将详情还重复获取敌军；有回放快照时仍生成敌军；触摸取消无论有没有拖动都重绘全场。

修复：
- 事务成功后递增非持久化 revision，按模型状态对象和 revision 复用整场备战属性。穿装、合成、布阵、培养和战果变化后自动失效；回滚恢复不同状态对象后也失效。
- 回放已有快照直接使用，不生成敌军；同时保留快照中的正确阶级。
- 触摸取消只清提示并复原拖动武将位置，不调用全战场 render。

验证：20 项详情与战斗属性专项通过，包括连续点击只准备一次、事务失效、回滚及回放禁止敌军查询。模拟器当前阵容属性查询 11/0/0ms，详情创建6ms；未将该结果视为真机帧率验收。

建议：继续将只读展示、局部交互刷新和全场渲染分开；以事务版本管理派生属性缓存，避免各面板自己重算阵容。
