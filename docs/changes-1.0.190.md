# 1.0.190 武将上阵羁绊触发特效

- 复用原客户端 fight-eff/bone21 的二进制 Spine、图集及纹理，原文件哈希记录于 evidence/original-bond-sources.json。
- 首次成档、升档以及新成员加入已生效羁绊时，相关上阵成员整组联动；同名成员按既有规则计数。
- 原图标、绕身光与脚底光同时播放；1 秒后光球以 0.5 秒飞向对应羁绊栏，同一角色多羁绊间隔 1.2 秒。
- 换格、普通重绘、撤下和未激活羁绊不触发；开战、切页统一清理补间与异步回调。
- 未改变羁绊数值、成员、门槛、永久解锁或存档。

## 结构与后续优化

触发查询、原版资源映射/时序配置、表现生命周期分为三个模块，并复用战斗羁绊算法。原版张飞效果与羁绊效果的二进制 Spine 加载逻辑类似；后续新增第三类原版动画时，可提取资源描述驱动的加载器，统一缓存、引用持有与解析失败重试，避免各效果模块复制底层实现。
