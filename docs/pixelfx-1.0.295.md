# 冰封与眩晕表现 · 1.0.295

冰封改为包住现有武将的半透明晶面冰壳，正常到期或真正驱散时散开短促冰屑；眩晕改为头顶循环星环。冰壳读取实际脚底，星环读取头顶并避开其他技能图标，两者附着于现有角色节点。

`control-status-vfx.js`只消费已成立的freeze、stun、cleanse状态事件，不参与免疫、伤害、控制时长缩减和技能触发。相同状态刷新取较晚结束时间，保留节点与动画相位；冰封与眩晕分别计时，可以共存。迟到已过期、零时长或已死亡目标不显示假控制。驱散立即解除，死亡、角色替换和离场直接清理；正常到期与驱散有冰屑，死亡不出现解冻假命中。

所有动画共用原生播放器的帧循环，倍速同步，速度0暂停，不增加控制专用计时器。播放器新增通用延长、停止、归属与结束回调。总节点上限仍为64，控制层独立预算48，普通PixelFX反馈维持20，控制提示优先于装饰火花。预算可配置，不代表真机性能验收。

## 配置与素材

- `game/play/control-status-vfx-config.js`：开关、冰壳比例、星环偏移、解冻时长与布局策略。
- `game/play/pixelfx-config.js`：全局开关、分组预算与优先级；关闭后回退原控制表现。
- `tools/pixelfx-export.config.json`：图集、帧率与导出预算。
- `source-assets/pixelfx/src/fx/status/control-stars.js`：仅借用MIT星环绘制器，不导出默认人偶动作。
- `source-assets/pixelfx/src/fx/ice/control-shell.js`、`control-break.js`：以同库Painter生成无角色身体的冰壳和冰屑。

新增3张图集源码PNG共135,996字节，发布副本48色PNG共30,267字节。全部18张图集RGBA8888展开约7.41MiB，不含mipmap及驱动开销。发布副本非透明背景JPEG质量从30调整为28，原始美术保留。MIT声明继续随游戏发布，源生成器与图库字体不打包。

重建：`node tools/export-pixelfx.mjs`。导出器检查本批bodyFree标识，直接绘制图库人偶的Frozen示例没有导入。

## 长期维护

沉默、定身等后续状态可复用此表现服务，继续由真实状态事件驱动。身体附着效果需保持bodyFree边界，需要贴肤时应提取实际模型遮罩。可逐步统一头顶图标与持续效果的布局登记，以适配密集状态组合。
