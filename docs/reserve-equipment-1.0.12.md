# 1.0.12

- 冰封逻辑仍为三秒战斗时间；修复特效从初始时刻乘当前倍速导致的中途切速跳变，改为逐帧累计。目标死亡、驱散及战斗结束仍正常清理。一倍速三秒、两倍速约一点五秒现实时间。
- 装备栏点击统一调用 equipped-item-details，闲置装备展示只读属性卡，穿戴使用原有拖动。基础属性、碎片库存、全队增益、介绍与进阶章节同卡展示；穿戴详情保留卸下。
- equipment-base-config 从原表导出装备基础属性，战斗面板与详情共享，烟斗生命400/魔抗65实际生效，仅穿戴者获得基础数值，全队增益独立。
- capacity:null 表示备战不限数量，所有获取和存档校验入口共用 reserve-policy；上阵人数仍受等级限制。保留显式有限容量兼容模式。
- 161项测试通过，包括变速累计三秒、123名武将保存恢复、上阵限制、烟斗属性归属。开发者工具验证123人时只建立10个可见人物节点，未更改真实玩家存档。
- 后续建议统一商店与图鉴装备属性查询，继续减少说明和战斗配置的分叉。
