# 1.0.197 保护期总等级留出优势

每章第一阶段的普通、精英、Boss，在人口内最强合法阵容基础上扣除1点总等级。优先降低最高等级并重新排序；全员一级时减少一人。玩家3、2、1对应敌军2、2、1，玩家1、1、1对应敌军1、1。

人数及逐名等级上限、无装备无援军、保护期属性倍率及独立首战教程保持原规则。玩家只有一名一级武将时，保留一名一级敌人作为最小可战斗例外，不能再降低到零人；空库存计划仍为空。

enemy-opening-config.js新增levelBudget配置（gap、minStar、minCount），独立保护版本升至3，已有旧保护快照在实际开战前迁移一次，预览只读、待领战报保持原样。第二至五阶段不受影响。

总等级预算和逐名上限在enemy-opening.js同一入口处理，避免普通、精英、Boss各自扣减而造成重复降级。新增混合等级、全一级、单人及空库存测试，并继续覆盖60章实际生成与存档迁移。
