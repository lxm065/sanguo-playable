# 1.0.135 本章难度循环

每章第一阶段保护不变；从第二阶段首次正式开战起记录一次已上阵队伍的静态战力，包含装备、装备进阶、天赋、羁绊等已有属性入口。第三至第五阶段沿用该基准，不再随玩家升级或换装重新取样。旧档已在中后段时，从升级后的首次正式开战建立基准；章节重开、新章新局会清除基准。

目标静态战力 = 本章基准 × 关卡类型系数 × 进度系数。普通0.85、精英1.00、Boss1.08；进度系数初始1，每次正式通关领奖增加0.04，最高3。战败完整观看视频并成功领奖后，进度系数乘0.8，最低0.5，本关和后续关卡共同使用回退后的系数，再逐关增加。普通重试不改变系数。所有参数集中于game/play/enemy-light-balance-config.js。

继续保留原有敌军人数、等级及配装限制，本关敌阵首次开战锁定。每关只汇总敌军面板，把目标战力转换为生命、攻击倍率（安全范围0.1至8），不运行预演、不显示整军中，也不重新汇总玩家战力。技能克制、控制、治疗等不会被静态战力精确表达，因此配置系数不是通关概率，也不承诺固定90/75/60胜率。

循环状态独立放在enemy-difficulty-cycle，属性估计与倍率换算留在enemy-light-balance。增长随成功领奖事务提交，视频回退随有效视频奖励事务提交；取消、过期或重复广告回调不降难，失败事务整体回滚。新制不再重复叠加旧版按次数削弱生命、攻击及装备的规则，但保留旧档此前已领取的减压，待领取历史战报不改写。

后续建议只通过离线实战样本调类型系数、每关增量和视频回退比例，避免再次引入每关动态追涨或现场胜率搜索。
