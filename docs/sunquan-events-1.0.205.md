# 孙权一级技能触发

用户确认：合成返还70%，泉水额外随机升级70%；返还合成前的同名同阶武将，泉水允许再次选中刚升级且仍符合等级条件的武将。以上为用户设定，不标为原版服务端概率取证。

实现：sunquan-skill-config集中配置一级概率与泉水选中策略。sunquan-skill为合成、泉水提供独立领域入口，种子、奖励、技能回执与主操作同事务保存。技能等级读meta.lordSkillLevels，不使用局内等级；未配置的高级等级不推测数值。

普通、随机、视频定向三种合成都可返还；返还是新的备战席实例，不复制装备。只在有效合成完成后判定一次，返还自身不递归。泉水先正常升级，随后独立70%判定并从更新后的合法池再选一次；无合法目标时仅保留正常升级，不虚报触发。泉水复制和装备选项不应用此概率，也不额外触发合成返还。

成功保存后用已有圆头像横幅展示；合成显示返还武将，泉水结果列出正常升级与追加升级。重绘、重载、旧事件点击不重复执行奖励。失败事务不播放成功横幅并回滚种子、等级、单位、回执。

维护建议：后续接主公觉醒时继续统一读取独立技能等级，由配置补齐高级规则，不在合成/泉水视图分散判断概率。当前只启用用户已确认一级。
