# 行军导航、章节重玩与连杀展示

本次修改仅涉及新导航外观、章节切换服务、商店广告入口排版，以及六杀七杀展示。不改变战斗伤害与商店金币奖励规则。

导航：以用户提供的龙纹红绸图为参考，经 imagegen 移除固定文字与外部底色，生成透明底图。素材保存在 game/skin-assets/common/march-header-dragon.png；来源见 source-assets/march-header.json。文字由真实章、节和标题生成，返回箭头继续打开既有保存退出/投降弹窗。尺寸和点击区域由 march-header-config 配置。

重玩：点击非当前的已通关章，弹出“新的挑战”。跳转继续当前路线，放弃才切换至所选章第一节。新增分页以访问早期章节；重玩时依然可选历史已通关章和最高开放章。重开清除局内金币、装备、经验与路线；保留永久通关、钻石、仓库、天赋、矿场和一次性领取记录。新局广告序号及教学run id递增，拒绝旧异步回调。未领取的结算须先领取。关闭确认框不修改存档。

商店：视频金币卡片调用共用 button-content 图文排版，真实摄像机图标 + 动态金额“500金币”，不再使用字符三角形。金额仍来自商品，领取仍经过广告完成凭据。

六杀、七杀：原先已配置两档语音，但文字横幅maxCount=5会跳过两档。现在加入金色描边动态文字，使用现有背景、双方头像、弹入缩放和淡出动画，不新增伪称原版的6.png/7.png；不改击杀归属、连杀时间窗口或伤害。1.0.106 已通过共用播报注册表补齐八杀与胜负横幅。

验证：34项针对性测试通过，覆盖真实章节重开事务、永久资产保留、读档、未来章拒绝、过期确认、写盘回滚、分页、确认按钮、导航热区、视频图标/广告回调、真实死亡事件触发六杀七杀、矿场及第三四章回归。透明图alpha通道已核对。尚未进行微信开发者工具/真机画面对照，也未上传开发版。
