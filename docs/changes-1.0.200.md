# 1.0.200 第二阶段过渡与无装备玩家基准

- 每章第二阶段的第一个实际战斗为普通关时，关卡系数为1.00，敌军无装备；事件不消耗首关保护，失败重试仍保持首关规则。
- 首关正式胜利领奖后更新正常难度系数，后续普通关恢复1.05关卡系数和原配装规则；精英及Boss系数保持1.20/1.35。例如普通增幅0.04时下一场目标为裸装基准×1.05×1.04，轻松获胜和恢复期仍按各自策略。
- 玩家基准选择最强合法阵容和评分时完全不纳入装备；穿戴、背包、装备进阶及装备专属技能均不抬高基准。天赋、羁绊等其他培养仍有效，玩家实际战斗装备不变。敌方装备仍计入敌阵实际静态评分。
- 旧档优先用历史基准阵容去装评分，缺历史阵容时使用当前裸装最强阵容；迁移取不高于旧基准的值，保存一次。历史培养快照不完整时只能保守迁移，不保证还原历史时刻的精确裸装值。
- 难度系数、广告次数及恢复目标保留；旧第二阶段首关的装备在预览中隐藏并在开战时清除，待领取战报保持原样。旧版已有三次广告减难不会重置为1。
- enemy-stage-two-opening.js统一首关识别与裸装规则，enemy-player-baseline.js隔离取样与旧档迁移。参数集中于enemy-light-balance-config.js，避免阵容选择和战力计算分别计入装备。

验证：全量720项通过；新增60章首关与后续普通关、装备进阶独立性、天赋有效性、旧存档及三次广告减难迁移测试。
