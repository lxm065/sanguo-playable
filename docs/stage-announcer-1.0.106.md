# 1.0.106 阶段难度与播报横幅

## 五阶段选值

敌方人数、等级由 enemy-stage-config.positions 的 0、0.25、0.5、0.75、1 选取各阶段原配置区间；第一阶段使用下限，第五阶段使用上限，中间阶段按比例取整递进。普通、精英、尾王共用最终敌阵裁定，保留首领身份。

第二章及后续章节复用既有五阶段区间：人数1–4、4–5、5、5–6、6；等级1–2、2、2–3、3、4。人数区间按现有可出战阵容+1下限抬升，最大18格；第一章第一节仍保留最多3名裸装的教学限制。每章第一场继续是单个裸装一级敌人。

第一章第2–5节保留总等级预算分摊，人数领先区间1–2，总等级领先区间0–3；按同一阶段比例取值，末节达到+2人/+3总等级，不把每名敌人全部拉高到己方最高星级。

原有资源预算不再二次抬升敌人星级。新敌阵开战时记录策略版本；老缓存先提供只读新规则预览，在开战事务中迁移一次；保留失败减压次数，避免装备系数重复打折。新版锁定敌阵不因临时上下阵、合成或页面重绘改变等级与人数。已有待领战报不改写。

## 播报表现

announcer-config 为语音文件与横幅标题的唯一注册表，包含 First Blood、Double Kill、Triple Kill、Quadra Kill、Penta Kill、Mega Kill、Godlike、Ultra Kill、Victory、Defeat。六七档主标题按用户指定的 Mega Kill/Godlike 命名，并保留六杀/七杀副标题；第八档显示八杀。音频文件沿用现有素材，不重新生成或替换语音。英文展示名不是自动转写结果。

原图横幅保留1–5档画面并增加英文字幕，其他档位采用金色描边文字、双方头像、缩放淡出。八杀以上按已有音频封顶档持续显示，不再直接丢弃横幅；敌方获得第一滴血时也可显示首杀横幅。远征与挑战胜负展示共用注册表。
