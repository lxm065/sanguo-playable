# 1.0.117 装备推荐与专属提示分离

- 恢复原有物理/法术攻击适配、职业与射程推荐，不再被专属名单覆盖。
- 专属身份单独查询，额外绘制武将红框。适配与专属均符合时同时显示推荐标签及红框；仅专属时不伪造推荐标签。
- 远征和多人对战使用同一实现；场上与备战席可见武将都参与，满装备槽仍显示提示。
- 红框尺寸、位置、线宽、颜色集中配置，内部透明，不遮挡武将。取消或结束拖动时跟随原提示统一清理。
- 不改变穿戴、属性、技能、伤害、数值或存档。未实现的新增专属技能继续保持待实现状态。
- 523项测试通过，覆盖仅推荐、仅专属、两者都有、两者都没有、可见性与节点清理契约。
- 开发者工具隔离局检查诸葛连弩：黄月英仅专属框，太史慈仅推荐标签，真实玩家存档未改变。

架构建议：后续将“适配理由”与“专属技能实现状态”作为独立展示信息，始终避免用身份名单替代基于实际属性的推荐策略。
