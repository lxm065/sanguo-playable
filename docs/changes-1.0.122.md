# 1.0.122 变更
- 击杀播报先按 battle-audio-config.killSide 检查阵营，只有我方击杀触发语音和横幅；敌方首杀不再占用我方首次播报。胜负播报不变。
- 羁绊按上阵数量累计，同名同阶、同名不同阶分别计数；场下单位不计入。基础羁绊与已解锁的特殊羁绊使用同一计数方式，特殊羁绊原有解锁条件不变。
- handbook-config.countDuplicates 控制重复计数；bond-count 提供图鉴预览与战斗的公共人数查询。远征、多人和敌军的羁绊均使用相同规则。
- 羁绊阈值及每档数值不变。重复敌军也会获得符合人数阈值的羁绊，这是统一规则带来的直接影响。
验证：528项测试通过，包含敌方首杀/连杀静音且无横幅、我方首杀保留、同名二人/四人激活、场下排除和面板战斗一致性。
架构：本次抽出公共计数入口，避免图鉴与实际战斗维护两套去重逻辑；以后扩展羁绊应复用该入口。
