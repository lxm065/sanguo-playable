# 第二章人数适配 1.0.62

原问题：1.0.61的阵容动态适配只计算平均阶级，普通和精英人数仍被旧六人上限与阶段固定人数限制。

新规则从第二章2/5开始生效：可用阵容人数取人口上限和持有武将总数的较小值，备战席也纳入，避免临时下阵刷新弱敌。普通敌人数至少为该数减1，精英等于该数，尾王含护卫至少为该数减2；仍保留阶段基础人数下限，最终不得超过棋盘及总部署容量。首节及其他章节沿用原人数规则。尾王扩充现有护卫，不复制首领。所有阶级、伤害倍率、随机浮动与失败缓冲不变。

玩家可用九人时，对应普通8、精英9、尾王7人。玩家有30名库存但人口为9时仍按9计算，不会无限扩兵；人口继续增长时允许越过9人，最多适配18格棋盘。

验证：40项领域及回归测试通过，包含第二章四个阶段的普通/精英/尾王人数、唯一UID、唯一站位、备战切换稳定、棋盘容量、旧章节保护和失败减压。微信模拟器隔离9对9精英战播放656个事件并结束，玩家原存档保持不变。未进行完整真机难度验收。

后续应将人数、阶级、装备与属性倍率作为同一关卡策略的四个维度一起检查，避免只调整平均阶级而遗漏人数成长。
