# 1.0.270 多人对战金币不足提示

“换一批”和“升人口”分别按当前金币与实际费用判断：不足时按钮文字显示红色，刚好够用或余额充足时使用共用按钮正常文字色，人口 MAX 不显示金币不足。每次操作及回合结算重绘时重新判断，原有消费校验不变。

红色在 challenge-config.js 的 ui.insufficientGoldColor 配置；ChallengeView.updateGoldButtonColor 集中处理显示，避免两个按钮使用不一致的判断。

验证：38 项挑战模式测试通过；源码与生成包各 6 项颜色边界检查通过；22 项发布模型检查通过。AppID wx7a597ac02546773f 与版本一致，构建包体限制检查通过。官方 CLI 上传 1.0.270 成功（退出码 0、√ upload），回执 evidence/upload-1.0.270-info.json，日志 evidence/upload-1.0.270.log，构建日志 evidence/build-1.0.270.log。尚未进行实际游戏画面及真机视觉验收；仅开发上传，未提交审核或正式发布。

后续优化建议：其他模式需要同类提示时，可在共用按钮组件增加费用状态展示接口，由领域服务提供余额与实际费用，统一配置正常色和不足色；展示接口不承担扣款，避免 UI 与交易规则耦合。
