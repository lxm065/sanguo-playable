# 1.0.137 视频回调到已通关难度

取消第二阶段起视频固定乘0.8的规则。每次正式胜利领奖记录实际战斗快照的进度系数作为最近通关锚点，再按原配置增加0.04。战败完整观看视频并领取后，回到该锚点；下次打赢继续递增。重复视频不在锚点以下继续打折。

普通关基准100、系数1.05：已通关进度1.08对应113.4，下一次进度1.12对应117.6；失败视频回到1.08即113.4，再获胜恢复1.12即117.6。例子验证的是目标静态战力，不能由一次胜负精确反推玩家战力。

类型系数保持普通1.05、精英1.20、Boss1.35，跨类型只回退公共进度系数，保留类型强度差异。第一阶段保护与原有重试规则不变。从第二阶段起，尚无通关记录时不跌破初始进度1；最高进度仍由配置限制。

每章战力仍只记录一次。旧版八折导致低于初始值的存档，在下一次正式开战恢复到初始下限。旧档缺少真实通关锚点时，最多回退一个配置步长并保存临时锚点，避免重复回调持续下降；之后以真实胜利记录替代。待领历史战报不重写，领奖、视频回调、写盘失败仍走原有事务保护。

难度状态与静态属性估算继续分离，后续只调配置，不引入现场预演或重新估计玩家战力。
