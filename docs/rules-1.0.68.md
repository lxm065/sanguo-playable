# 1.0.68 行为与验证

- 第3章起按图鉴英雄解锁表生成首领与护卫。解锁章末对应新英雄：4马超、7典韦、10小乔、14祝融、19甘宁、25孙尚香、32张辽、40貂蝉、50张角、60吕布。其他章节和小节轮换此前已开放英雄，首两章原编排保留。路线仍复用模板，不将生成首领称为60章手工制作内容。
- 兵种刷新优先扣1枚招贤钱（物品8），同样得到2阶候选，不占视频刷新额度。道具用完才走视频。旧按钮带有战果与刷新序号，避免重复点击消耗道具；失败写盘回滚。
- 最后一命战败显示10秒复活倒计时。开始观看时暂停剩余时间，取消后续计时，完整观看恢复主公满血并赠一名2阶武将，保留关卡位置与敌阵快照。超时或投降进入本局结算。未完成视频或缺少凭据不能复活。
- 复活计时从战斗回放结束、复活面板出现时开始，不会在模拟出战果后、动画尚在播放时提前消耗。重绘不会重新获得10秒。
- 袁绍每次新远征第一次正式战斗必定成功；同一局重载不重置。其后基础1/3，连续两次未中后保底。演武不触发。
- 备战倍速切换只修改按钮与计数文本，不重建棋盘，不扣次数；点击开始在开战事务中扣除。战斗中按钮不接受切换。倍速上限仍为2。

验证：349项测试通过，发布包20项专项测试与22个模型检查通过。模拟器独立内存档实际点击招贤钱按钮后道具为0、候选2阶、视频消耗0；切速前后棋盘节点完全相同且次数不变。复活按钮在模拟完整观看后生命3、赠将1、待领奖战果清除；实际微信广告验收尚未进行。测试前后玩家存档一致。

架构建议：持续让章节编排、刷新支付方式、复活状态与技能保底各由单独领域服务管理；后续用统一的显式奖励支付凭据替代可选参数，减少界面状态与视频回执交叉处理。
