# 1.0.72 闪烁、技能计时、敌人成长与装备滑动

- 赵云原本已有闪烁到最高攻击目标附近空格并攻击的逻辑，但移动按跑步补间播放，原Blink主要用于命中。现在瞬移事件携带blinkStrike标记，原地及落点各播放Warcraft III的NightElf/Blink/BlinkCaster.mdx导出帧，人物直接落位。复用已有blink.png，不增加资源、不修改目标选择、倍率与冷却。技能仍按原有阶级解锁。
- 甄姬基础冷却：冰星7秒、冰封10秒、暴雪16秒；暴雪引导与三波伤害合计3秒。skill-timing-config.js统一图鉴与运行名册，保留原始导出作为溯源。辉煌自减20%/队友10%和装备减冷却仍按既有规则生效。
- 所有章节第五节新敌阵最低4阶，包含普通、精英、首领护卫。原有首领更高阶配置保留。后续章节基础人数和属性曲线复用第二章五小节配置，避免回到旧上限曲线。
- 第二章起章节倍率=1+0.05×(章-2)+0.2×普通关金币相对第二章的增长比例，即当前金币规则下每章增加0.07。永久成长另乘天赋与装备倍率：天赋等级每级0.004、天赋节点每级0.003，合计最多35%；全部可进阶装备的平均阶级每阶0.025，最多25%。配置enemy-growth-config.js。计算不读取当前现金及临时穿戴，不会因为花金币或卸装备改变难度；展示和战斗共用倍率。此为本地平衡策略，不宣称恢复原服算法。
- 开战锁定敌阵和倍率，复活视频仍只衰减装备增益。已有版本化快照不追改等级，新遭遇才采用4阶底线与新倍率；没有版本的早期兼容档保留旧迁移逻辑。
- 远征和挑战装备栏移除箭头。水平滑动翻页，上下拖动穿戴，系统取消不翻页，边界不循环。滑动只更新装备容器，角色、动画、挑战倒计时保持。方向越过阈值后锁定，共用equipment-swipe服务，避免两种玩法手势分叉。

验证：375项源码测试，包含甄姬全阶及图鉴一致、三波真实伤害、闪烁目标与7倍伤害不变、两端原素材调用、跨章成长、所有类型第五节4阶、敌阵快照、触摸取消与挑战装备上拖/横滑区分。

长期建议：将技能元数据与原始配置覆写统一为一个领域查询服务，避免新增计时再分别修改图鉴与战斗；敌人成长按版本化遭遇配置管理，记录章节、永久培养、随机扰动各项贡献，便于后续基于实际通关率调权重。
