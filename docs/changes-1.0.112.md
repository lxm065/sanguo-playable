## 架构建议

装备名称已由 equipment-theme 统一，但图鉴预置文案与战斗效果仍有重复数据。下一步可由同一技能配置生成说明、推荐和固定冷却约束，减少改名或改机制时漏改某个入口。此次专属参数集中在 chitu-config，避免把英雄 ID 与增益数值散落到 UI。
