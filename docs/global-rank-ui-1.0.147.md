# 排行榜界面对齐 · 1.0.147

- 全服榜和好友榜共用关卡排行/挑战排位标签、六行分页、表格坐标与成绩说明。
- 每行显示名次、微信头像、昵称、章节小节/段位星级、副说明，以及右侧原始通关数/排位积分；底部统一显示页码、我的进度/段位和个人名次。
- 共用 rank-format.js，构建时复制到开放域，保持好友资料隔离，不跨域读取好友头像或 openid。
- 全服榜从后台已授权资料读取 avatar_url，仅加载微信 HTTPS 头像；缺失或失败显示占位。图片使用独立 Sprite 子节点，销毁榜单时释放纹理，迟到回调不会恢复头像。
- 好友榜新增“全服排行榜”按钮，两榜双向切换都清理前一榜单生命周期。

验证：全量 597 项测试通过；最终头像渲染修复后的相关 6 项测试通过。开发者工具实际双向切换验证成功，实际微信头像已渲染，纹理 132×132。截图 evidence/global-rank-ui-1.0.147.jpg，切换/头像检查记录位于 evidence/rank-*-147.json。
