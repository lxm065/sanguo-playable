# 1.0.148 连续视频保留原恢复目标

再次战败视频只降低恢复起点，不再把恢复目标改成较低的最近失败值。恢复目标取本局已记录目标与当前失败点的较大值，增长步幅=(目标-新起点)/recoveryWins。突破原目标后遇到更高失败点才上调目标，新章或重开仍清空。

例：113.4通关、117.6失败，视频回113.4；若仍失败再次视频降至96.39，随后四次增幅为101.6925、106.995、112.2975、117.6。目标不再降为113.4。因为终点保持，起点下降越多，每步恢复的绝对增量也越大，这是固定四步的结果。

读取存档和跨阶段保留目标。旧版已经覆盖掉的更高历史目标没有完整记录可还原，因此沿用存档现有目标，之后不再下调；不伪造缺失的历史战果。

原先的连续视频实际减难、初始下限豁免及真实敌军生命攻击测试继续保留。不增加战斗预演，不改人数、等级、配装和胜负判定。
