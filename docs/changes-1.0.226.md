# 马超 · 虎头湛金枪：虎魂熔炉

## 行为

- 马超装备 7007 后，原有吸血溢出产生护盾时开始计时，不额外凭空生成护盾。
- 连续保持护盾 2 秒后自动引爆，先清空剩余护盾，再对当前周围一格（包含斜角）的所有可选中敌人造成伤害。
- 按每个受击目标的最大生命值 × 15% 计算基础法术伤害，再走魔抗及通用减伤结算。没有额外固定伤害，不暴击，不触发爆炸吸血连锁。
- 补盾不刷新当前计时；提前破盾、死亡取消这一轮。新获得的护盾重新计时，同名多件不重复引爆。魅惑期间暂缓主动引爆，恢复后仍有盾才触发。
- 原武器基础属性、吸血和溢出护盾上限保留；其他武将不获得马超专属引爆。

伤害口径采用用户给出的灵魂熔炉参考中的目标最大生命值思路；2 秒及 15% 按用户指定，不照搬参考技能当前数值。参考：https://wiki.leagueoflegends.com/Sion

## 表现与配置

红色透明全身护盾和脉动光圈持续蓄能，引爆时在马超当前位置播放火焰爆发与环形冲击波。破盾仅消散；死亡、回放退出清理补间与粒子。复用项目原生特效资源，无新增贴图下载。

weapon-exclusive-config.js 的 7007 项集中控制等待时间、格距、生命来源、比例、伤害类型及表现尺寸颜色。machao-shield.js 管理护盾周期；machao-shield-view.js 仅处理表现。equipment-effects.js 在吸血溢出时通知，统一伤害入口在盾耗尽/死亡时通知。

## 验证与后续设计

全量 796 项测试通过。新增测试覆盖 2 秒边界、补盾、破盾重获、死亡、归属、重复装备、移动范围、斜角、无敌、敌我区分、目标生命比例与魔抗、真实战斗以及特效清理。

后续建议将 equipmentShield 从单一数值逐步改为按来源标识的护盾账本，统一发出获得/消耗/破裂事件；目前容量护盾仅有本装备来源，独立生命周期模块已经隔离了引爆规则。新增其他容量护盾时应由账本明确吸收顺序和可引爆来源，避免误消费队友施加的盾。

开发上传与真机观感验证分别记录；当前未完成真机验收。
