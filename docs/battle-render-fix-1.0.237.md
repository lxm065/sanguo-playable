# 战场控件缺失修复（1.0.237）

1.0.233的手牌扫描优化引用了未声明的 mergeEligible。renderBattle 先绘制阵容和手牌，第一张手牌名称处抛出 ReferenceError，后续顶部HUD、底部栏和开始按钮因此未执行。不是存档损坏或控件被隐藏。

补充 renderReserve 局部变量，仍在每页绘制前仅计算一次可合成集合。没有更改玩家数据或战斗规则。

新增回归实际调用生产 renderReserve，覆盖1、6、30张手牌；战场入口测试执行真实手牌绘制后验证顶部、底部、开始、倍速及次数控件都创建。引擎节点与无关子面板使用测试替身，不能代替手机截图验收。

后续应将实际页面入口冒烟检查纳入视图优化验收，避免仅测试计算辅助函数而漏掉调用端变量错误。

验证：817项测试与22项模型检查通过，微信开发版1.0.237上传成功（exit 0 / √ upload）。真机显示待验证。
