# 第五章钻石矿场

已实现：第四章通关后首页展示第五章矿场预告；第五章章末奖励领取后展示要塞入口指引；进入要塞自动定位矿场，展示建造指引；点击解锁打开费用确认；支付7500钻石进入3小时建造；到期转为Lv1并可领取；第八章通关开放下次升级。

引导采用原版22634两段文案、24-1/24-2原音频、浮动金色箭头，人物沿用三国版甄姬。音频出处与哈希见 source-assets/diamond-mine-audio.json。箭头销毁停止动画；计时器销毁清理；每秒只更新倒计时，到期才重绘页面。

## 数据边界

等级、费用、建造时间、容量、升级章节从原始 fortress_cfg id=1 完整转录；红色宝箱6级解锁来自 assets_cfg 15；预告来自 foretell_cfg 5。服务端生产参数尚未恢复，当前采用独立可配置本地规则：每3小时每格2000钻石、建造完成可领首格、每日建造及生产加速各5次、每次缩短1小时。2000钻石是截图6的已知实例，不代表已恢复完整随机宝箱奖励表；品质预览已保留，但当前本地产出不实现随机品质。所有差异集中在 diamond-mine-config.production 并明确标记来源。

建造加速复用广告适配器；生产加速复用分享离开返回软校验，不证明已实际发送给好友。广告当前仍由现有项目环境配置决定。

## 架构演进

矿场经济服务、配置与视图已分离，通过注入时钟和进度服务验证离线行为。后续接入原服数据时，建议将 production 参数替换为生产策略接口：保持扣款、领取、加速事务不变，仅替换产出计划与奖励来源，避免重写界面。

classic-view.renderCamp 仍承担章节礼包、仓库和黑市布局。后续扩展其他工坊时，宜提取要塞面板注册表，由各面板提供高度、解锁条件及引导锚点，从累计高度计算滚动目标；这样可消除当前矿场固定 focusOffset 在面板增删时漂移的风险。
