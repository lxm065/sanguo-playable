- 典故取自曹植《洛神赋》“翩若惊鸿，婉若游龙”，标为古籍取意；羽扇及魅惑能力是游戏创作，不作为甄姬历史遗物叙述。原文：https://ctext.org/wiki.pl?chapter=943054&if=gb

## 设计与验证

控制判定、命中与到期放在 charm-exclusive.js，透明矢量心形表现放在 charm-exclusive-view.js；时间、尺寸、颜色与动作集中在 weapon-exclusive-config.js。阵营不被临时改写，避免影响胜负、战利品及羁绊。控制命中将已排队的旧攻击标为取消，保持队列索引稳定。

新增测试覆盖距离、归属、冷却、不叠加、四秒到期、原队友互殴、独立目标、自伤防护、无敌与召唤物、旧弹道取消、重复控制及表现清理；全量测试和构建记录见 evidence 对应版本日志。真机观感需单独验证。

后续架构建议：将嘲讽、魅惑、沉默和变羊统一成控制策略接口（可行动、可施法、敌对关系、取消旧动作），由战斗调度器组合查询，减少 expedition-combat.js 与各技能模块间重复判断。装备名称及器型目前有多个导出表，建议从 equipment-theme 生成目录及章节预览，并在构建时校验一致性。
