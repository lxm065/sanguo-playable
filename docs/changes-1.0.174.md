# 1.0.174 四连胜加速

- 所有正式胜利累计 consecutiveWins，跨阶段与重载保留。第4胜后比例增幅至少20%，第5胜40%，第6胜及以后80%；不要求战报判定轻松，险胜也属于连续胜利。
- 前3胜沿用原轻松/普通/险胜增幅；比例下限与原增幅取较大值，不重复相乘或相加。新增长作用于下一场未锁定关卡。
- 失败或视频回调清零连胜。视频后三次恢复期间不累计加速连胜，原失败目标保持；恢复后重新累计。
- 普通起步轨迹：1.04、1.08、1.12、1.344、1.8816、3.38688、6.096384、10.9734912。
- 原难度系数3倍上限调整为30，最终属性倍率8倍上限调整为80，保留有限数值保护。人数、等级、配装规则及每章固定战力基准不变。
- 旧存档没有真正连续胜场时只使用已知轻松连胜数，不将累计 wins 误当连续胜场；无已知数据从下一胜开始计数。无需清档，当前已锁定敌阵不重算。
- 增幅与上限是配置初值，不保证固定第几场必败；需要真机战报反馈校准。策略集中于 enemy-win-growth，持久化计数仍由 enemy-difficulty-cycle 在既有领奖事务维护。
