## 验证

- 519 项自动测试通过，含专属正反例、普攻特效、技能刷新、暴击、基础属性保留、头顶挂载及帧索引。
- 开发者工具400ms与1000ms采样均有已加载帧，parentIsHead=true；头顶高度由57自动校准到64，效果偏移42；2600ms节点已销毁。

- 未进行手机真机验收。

## 后续架构建议

装备效果仍有普攻附加、静态属性、运行期主动被动三条路径。后续可统一为配置驱动的效果阶段处理器，共用资格判定，避免新增专属装备时漏掉吸血等静态被动；保留装备属性与技能两个独立层，减少改动对旧存档与进阶数值的影响。
