# 雷火技能与远程弹道 · 1.0.292

雷电采用蓄光、动态蓝白电弧与命中电火；火柱采用低亮地面预兆、实际命中后的火柱与扩散、渐隐收尾；炎浪采用跟随目标的拖焰飞行与逐受击目标爆光。太史慈火箭和灼烧增加对应命中火星。祝融保留刀刃、五刃阵列与回旋返程，升级拖焰和火柱/火星层次。

通用远程覆盖带风尾弓箭、火球、冰晶箭、水系光核、灵力光核与毒色弹。甄姬保持水系配色，小乔普通飞扇、机关弩与专属技能仍保留其专用表现入口。飞行时长仍读取attackDelay或真实impactDelay，终点跟随目标实时位置。表现层不生成额外伤害，不调整伤害类型、次数、范围、射程、冷却、控制、奖励或存档。

## 实现与配置

- `game/play/elemental-vfx.js` 统一施法预备、弹道、实际命中和死亡清理；范围主效果按同次命中去重，多重施法按预计命中时间保留独立定位。
- `game/play/pixelfx-config.js` 集中管理资源、配色、尺寸、层级优先级、时长与数量上限。最多同时存在20个新增节点；低优先级火花不会挤掉火柱、蓄光和主要弹道。关闭总开关恢复既有路线。
- `game/play/native-effects.js` 共用缓存、图集锚点和唯一帧循环；播放速度0正确暂停，死亡取消未完成蓄光，离场停止计时器。
- `tools/pixelfx-export.config.json` 配置截取时间窗、中心点和缩放，离线裁掉冗余留白并保留直通透明度。累计15张图集，PNG约1.025MiB，RGBA8888约6.43MiB；均不超过1024像素边长。上述纹理估算不含mipmap和驱动开销。
- `source-assets/pixelfx` 保留35个实际使用的上游文件、来源摘要、MIT声明，以及基于同库绘制助手制作的无场景道具电弧。默认人偶与图库字体未引入；生成器和源素材不随游戏发布。

重建：`node tools/export-pixelfx.mjs`。新资源在发布副本采用配置的48色调色板；为容纳新增动效，非透明背景发布JPEG质量从36调整为30，原始美术和动画源图保留。
