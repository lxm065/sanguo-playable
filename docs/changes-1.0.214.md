- 青龙偃月刀：任意敌方单位阵亡均通知所有存活且装备青龙刀的关羽，不再要求关羽击杀。追斩导致的敌方阵亡也继续触发，死亡入口保证一个单位只结算一次死亡。

- 独立身体缩放层避免转向/受击覆盖体型；撤销恢复层级。独立图标不覆盖周瑜的下一技能增益。

## 重复装备核对

同一角色的同名专属效果不叠加、不增加触发次数。黄忠多把养由弓仍每次命中叠5%、最多30%。装备基础属性按既有规则累计；实测三把比一把额外增加300攻击。多名匹配武将各自持有装备独立触发；多个周瑜发放的10%下一技能增伤只刷新、不叠加。

759项全量测试通过。新增覆盖队友击杀通知关羽、重复装备、典韦重复刷新/撤销、目标死亡、独立缩放层和真实战斗9秒抛投。未完成真机动态画面验收。
