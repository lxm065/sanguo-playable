# 1.0.69 羁绊红点、小节定位与敌人阶级

- 羁绊文字右上显示可升级红点。与现有棋子合成箭头共用同名、同阶、三枚判定，包含备战席；满阶、待结算与交战期间不亮。合成后重新计算，不写红点存档。
- 小节普通与视频领奖后直接打开新小节地图，滚动偏移归零。地图入口另按章节/小节键检测变化，避免旧滚动位置带入新路线；同节重绘保留玩家滚动位置。
- 根因：旧最低阶只对第二章定义，其他章沿用英雄初始阶级。现在全章节共享小节下限：1/2/3/4/5节分别至少1/2/2/3/3级，普通敌人、精英、首领护卫都应用。独立首领更高等级保留，不把强敌降级。
- 已生成战报不改写。旧敌阵快照在战报领取后，下次开战前仅向上补齐最低等级，保留人数、身份、位置、装备、装备辅助重试次数及基础倍率。

验证：353项测试通过，涵盖各章普通/精英/首领等级、旧战报保护、红点合成前后与地图小节切换。模拟器独立内存档观察羁绊红点，合成后红点为false；实际点击小节奖励后page=map、offset=0、section=2；第二节敌人等级为2；玩家存档前后不变。

长期建议：所有章节成长下限由同一配置入口维护，独立章节只定义差异；界面提示继续复用领域判定，避免出现可升级红点与实际合成条件分叉。
