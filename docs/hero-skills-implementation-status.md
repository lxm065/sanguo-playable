## 小乔本次实际规则

1. 一阶霜华：基础冷却7秒，选择全场当前生命最高的可选敌人（同血量按ID），300%攻击力法术伤害、周围1格溅射；仅敏捷目标减攻速25%，持续4秒。按魔抗、统一减伤与控制抵抗结算。
2. 二阶凝霜屏：基础冷却15秒，选择损失生命绝对值最多的受伤友军（含自己）。待机资格按未引导、未抛飞、未处于本屏/七进七出解释，不要求停止普通攻击等待；3秒不能移动、普攻或主动施法，护甲+1000，每秒回复目标最大生命15%，共3次。没有合适目标不消耗冷却。无敌/不可选中不属于此技能，法术伤害仍按魔抗承受。治疗沿用统一减疗和决胜规则，不复活；已生成保护不因小乔死亡取消。
3. 三阶流霜焰：基础冷却3秒，选择全场当前生命最高的可选敌人；通常300%攻击力、力量目标600%，法术伤害，无额外溅射。
4. 四阶寒江凝雪：基础冷却20秒，最高血可选敌人冻结5秒，每秒150%攻击力法术伤害，共5段；控制抵抗沿用已有规则，目标死亡后不继续伤害。

四技能按阶级解锁、独立计时，受已有冷却缩减、控制与行动间隔影响；不保证冷却就绪当帧立刻施法。每次实际主动施法接入霜鸾护佑；开局2秒护佑和后续12秒独立冷却保留。

## 架构维护建议

当前补齐使用独立的warrior-skills规则执行器及warrior-skill-view表现层，动态范围任务与普通命中共用最终伤害入口。最后奋战由独立dianwei-last-stand模块拦截致命伤并经统一死亡回调结束。下一步应把各模块的负面状态统一为带类型的状态服务（来源、免疫、刷新、清除、表现共用），取代分散的Until字段写入；典韦已撤销召唤，后续甘宁分身应另行引入统一召唤工厂与回放事件。这样新增控制或召唤时不必同时修改多个技能文件，也能避免遗漏免疫入口。
