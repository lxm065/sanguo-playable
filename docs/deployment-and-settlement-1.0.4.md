# 1.0.4：落子推荐与投降结算

## 本次规则

- 拖动武将时高亮合法落子格。按实际射程选择前、中、后排；优先排满则寻找次选排。推荐排不强制放置，满人口时保留交换位置功能。
- 行军地图返回面板中的“投降认输”返回远征首页，弹出失败结算。
- 用户确认规则：每胜利通过一个战斗关卡获得10钻石；完整视频领取为每关20钻石。未通关、失败、训练、地图商人等事件不计战斗通关数。不再有固定40钻基础奖励。
- 投降时保存奖励快照，领奖前不能开始下一局。普通与双倍互斥，领奖和清理本局进度采用同一事务；重复点击、重新加载不重复发奖。
- 分享按钮使用真实已接入的普通分享能力，标签为“分享本局”，不声称已实现录屏视频分享。

## 设计与配置

推荐查询/绘制分别放在 `deployment-view.js` 的只读 query 与 show/clear 中，偏好和样式来自 `deployment-hints.js`。
结算服务 `run-settlement.js` 只负责快照与原子领取，金额来自 `run-settlement-config.js`；页面由独立 view 绘制。
后续可将章节奖、投降奖、签到奖的共同“快照—广告凭据—原子领取”抽成奖励服务；保留各玩法的资格判断，避免把不同进度规则塞进统一大函数。本轮不扩张重构范围。

## 发布图像预算

开发高清源图不变。独立发布目录按人体有效像素预算重排动作图集，至少80像素，目标84；保持全部动作帧、帧时刻、骨骼尺寸、坐标和朝向不变。主公立绘宽320，模型调色板96色。预算在 `tools/wechat-release.config.json` 集中配置。
`tools/verify-release-models.cjs` 对照源文件验证21名武将帧顺序、边界、像素预算和未改动的骨骼时间轴。
