# 1.0.141 订阅模板配置

用户提供的微信后台模板 ID 已配置在 `game/play/fortress-subscription-config.js`。

| 类型 | 业务字段 | 微信字段 |
| --- | --- | --- |
| 建筑升级完成 | buildingName | thing1 |
| 建筑升级完成 | completedAt | date2 |
| 宝箱解锁完成 | chestType | thing2 |
| 宝箱解锁完成 | tip | thing3 |

字段来自用户的模板详情截图，仅使用实际选定的两项字段，不增加当前等级等未选字段。客户端点击建造、领取时申请订阅；授权拒绝不影响玩法。

本次字段配置为后续服务端发送提供映射，尚未接入订阅结果上报、服务端任务调度和微信消息投递。上传开发版不代表离线提醒已上线；需要另行验证真机授权及消息送达。

架构建议：后续以服务端建筑完成时间生成幂等提醒任务，客户端只负责申请订阅和展示状态，将模板映射与发送服务分开，避免客户端计时承担离线投递。
