# 1.0.195 首阶段保护规则

- 所有章节第一阶段普通、精英和Boss使用同一规则：敌军人数与逐名等级分布跟随人口内最强合法阵容，不增加额外高级名额；全部不带装备、不追加援军。
- 全部持有卡牌参与最强阵容选择，高级卡放在场下不降低敌军等级。持有卡不足人口时不补虚构人数。例如最强阵容为3、2、1级三人，对应敌军也是3、2、1级三人。
- 首战一名裸装一级敌人的独立教学保护保留；原有保护期属性倍率上限保留。首阶段Boss取消固定二二二一一及三件装备，改用统一保护规则。
- 首阶段旧敌阵以独立openingPolicyVersion迁移：预览只读，实际开战保存，待领取战报不修改；新锁定敌阵重试不重抽。第二至五阶段不触发此迁移，难度增长和视频恢复规则不变。
- 配置入口enemy-opening-config.js；人数和等级计划、配装清理及版本判断集中在enemy-opening.js。opening-boss.js仅保留兼容入口，避免首阶段Boss与普通关再次出现规则分叉。
- 回归包括60章三类节点、混合等级与场下高级卡、人口与库存数量边界、裸装及无援军、旧缓存迁移、锁定重试和待领取保护。
