# 许褚全身金焰与超时决胜

## 许褚 · 虎卫坚盾

金盾改为脚底至头顶的尖焰轮廓、内外两层金光和上升火焰，覆盖全身并持续脉动。原触发条件、50%伤害吸收、3秒持续和15秒冷却不变。刷新、死亡、离场清理；到期使用战报时钟，途中加速也不会延长盾效。

## 决胜阶段

- 原60秒时间结束不再直接判负。继续模拟双方实际战斗，只有正常战斗结果才结算。
- 双方伤害乘2；回放速度在当前选择的速度上乘2，不额外扣加速次数，结算恢复原速度。
- 用户确认持续回血情况下逐步削弱治疗。默认在进入决胜后的30个战斗秒内线性从100%降至0%；回血、技能治疗、吸血及吸血溢出护盾都使用同一治疗倍率。
- 反伤、基于已结算伤害的溅射不再次乘2；独立技能、普攻和装备伤害统一增幅。
- 显示“决胜 · 速度×2 / 伤害×2 / 治疗递减”。早于倒计时结束获胜不触发决胜。
- 对病态数据或永久堵路保留1800个额外战斗秒的技术保护；仍有双方存活时抛出未决错误，不生成玩家败局、不结算假战果。原有同时阵亡的平局语义保留。

## 配置、测试与后续设计

battle-overtime-config.js 集中定义速度、伤害、治疗衰减与技术保护边界；xuchu-aura-config.js 定义金焰轮廓、颜色和尺寸。模拟、回放和护盾表现分别由独立模块负责。

全量804项测试通过，新增覆盖双边双倍伤害、超时后真实胜负、高回血对局、治疗归零、反伤防重复增幅、速度恢复及金焰清理。既有技能短时窗测试显式关闭决胜，保留原观察窗口；旧的60秒判负断言改为新行为验证。

后续建议：将 damage 的位置参数整理为带来源、伤害类型和已应用增幅标记的伤害上下文，避免反伤/溅射对派生伤害重复增幅；逐步统一补间与原生粒子的战斗时钟，确保所有持续表现都能在阶段变速时精确同步。
