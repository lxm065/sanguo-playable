# 1.0.220 丈八蛇矛擒敌连刺

触发：张飞实际装备7005丈八蛇矛，丈八擒敌（12091）成功命中存活敌方武将。命中后立即眩晕目标3秒，拉拽表现结束后对同一目标快速连刺5次；间隔0.16秒，每次按100%攻击力造成真实伤害（伤害比例未由用户指定，本次采用可配置默认值）。忽略护甲、魔抗，不暴击；不转移目标，不递归触发普攻装备效果。

目标被擒敌直接击杀时不触发；连击中目标阵亡停止剩余段数。张飞死亡或受眩晕/沉默打断时沿用持续动作队列规则取消后续段数。同名装备不重复触发。施加眩晕不会缩短原本更长的眩晕。未装备、其他武将、非擒敌技能与召唤物不触发。

每次有效伤害有对应快速攻击动作及命中刀光；眩晕状态由实际控制事件显示。专属说明已接入图鉴，保留丈八蛇矛图标与原基础属性。

配置：weapon-exclusive-config.js 的7005条目集中管理触发技能、眩晕时长、攻击次数、伤害倍率、间隔及表现参数。zhangba-exclusive.js封装命中后的调度，避免扩大通用技能分支。

测试覆盖实际战斗五段伤害、高抗性不减伤、3秒眩晕、重复装备、无装备、错误武将/技能、目标提前阵亡、五次动作和刀光。未进行真机动态视觉验收。
